## 维护约定

- **blueprint 锚点依赖**：`blue28.md`/`blue29.md` 引用 `FUTURE5`/`FUTURE6` 条目编号，`blue35`/`blue38` 引用 `design.md`——合并/删除本文档时必须同步 blueprint 引用。
- 新增未来方案优先追加到 `FUTURE6.MD` 之后的新文件，并在上表登记。
- 各文件重叠部分为模板框架（背景/目标/风险矩阵/DoD/里程碑），实质内容按阶段递增，非重复实现。
