# go-on GUI 使用指南

go-on 提供功能丰富的图形用户界面（GUI），涵盖对话交互、工作流管理、提示词模板、系统配置等功能。

> 相关文档：[提示词模板系统](prompts-guide.md) | [工作流配置](workflow-config.md) | [协议配置与 Zed 集成](protocol-guide.md)

---

## 主窗口结构

go-on 的 GUI 主窗口由以下三部分组成：

1. **工具栏（Toolbar）** — 位于窗口顶部，提供快速操作入口（新建会话、设置等）
2. **Tab 栏（Tab Bar）** — 位于工具栏下方，显示所有可用 Tab 标签
3. **内容区（CentralPanel）** — 占据主窗口主体，显示当前选中 Tab 的内容

---

## 所有 Tab 功能简介

| Tab       | 名称         | 功能说明                                             |
|-----------|--------------|------------------------------------------------------|
| Monitor   | 监控         | 实时显示系统运行状态、性能指标、日志信息             |
| Chat      | 对话         | 与 AI agent 进行交互对话，核心功能页面               |

| Workflow  | 工作流       | 查看和管理 workflow 执行状态                         |
| Prompts   | 提示词管理   | 浏览、搜索、管理提示词模板                           |
| Autotune  | 自动调优     | 自动调优系统参数和模型配置                           |
| Risk Decision | 风险决策 | 高维风险投票决策面板（默认开启，可在 Settings 关闭） |
| Security  | 安全         | 安全管理、权限控制、审计日志                         |
| Config    | 配置         | 查看和编辑配置文件                                   |
| Providers | 提供商       | 管理 AI 模型提供商和 API 密钥                        |

## Chat Tab 详解

Chat 对话页面是 GUI 的核心功能，包含以下组件：

### 左侧会话列表

显示所有历史会话，支持：
- 点击切换会话
- 右键重命名 / 删除会话
- 搜索历史会话

### Agent / Model 选择

- **Agent 选择** — 从可用 agent 列表中选择目标 agent
- **Model 选择** — 选择具体的 AI 模型，支持按提供商筛选

### 模式选择

| 模式       | 说明                                         |
|------------|----------------------------------------------|
| Ask        | 提问模式，向 AI 提问获取回答                 |
| Plan       | 计划模式，AI 输出结构化计划后执行             |
| Edit       | 编辑模式，对已有内容进行编辑修改             |
| Safeguard  | 安全模式，启用额外的安全检查                 |
| Full Auto  | 全自动模式，AI 自主决策和执行                 |

### 输入框操作

- 输入文本后按 **Enter** 发送（**Shift + Enter** 换行）
- 输入 `/` 触发命令补全列表（参见[提示词模板系统](prompts-guide.md#chat--命令)）
- 点击提示词模板可插入到输入框
- 选中外部文本后，在内容区右键选择 **Insert to Chat** 发送到 Chat 输入框

### 提示词模板插入

提示词模板可以通过以下方式插入到 Chat 输入框：

1. **Prompts Tab 插入** — 在 Prompts Tab 中浏览或搜索模板，点击 **Insert to Chat**
2. **`/` 命令** — 在 Chat 输入框直接输入 `/模板id` 展开模板
3. **AI 自动调用** — AI agent 通过 MCP 自动选择合适的模板

> 详细了解模板系统请查看[提示词模板系统](prompts-guide.md)。

## 键盘快捷键

| 快捷键               | 功能           |
|----------------------|----------------|
| Ctrl / Cmd + N       | 新建会话       |
| Ctrl / Cmd + L       | 清空输入框内容 |
| Ctrl + 数字（1-9）   | 快速切换 Tab   |
| Ctrl + ,             | 打开设置页面   |
| Enter                | 发送消息       |
| Shift + Enter        | 换行           |

## 设置页面

设置页面分为以下几个部分：

### 核心功能开关

控制各 Tab 的显示/隐藏：

| 开关             | 对应 Tab   |
|------------------|------------|
| 监控开关         | Monitor    |
| 对话开关         | Chat       |
| 技能开关         | Skills     |
| 工作流开关       | Workflow   |
| 提示词管理开关   | Prompts    |
| 自动调优开关     | Autotune   |
| 安全开关         | Security   |
| 配置开关         | Config     |
| 提供商开关       | Providers  |

### 高级功能开关

| 开关               | 说明                           |
|--------------------|--------------------------------|
| 多 Agent 协作      | 启用多 agent 协同工作模式       |
| 自动路由           | 自动选择最佳 workflow 和 agent  |
| 向量检索           | 启用知识库向量检索能力           |
| MCP 集成           | 启用 MCP 协议外部工具集成        |

### 系统设置

| 设置项           | 说明                         |
|------------------|------------------------------|
| 日志级别         | 控制日志输出详细程度          |
| 自动保存间隔     | 自动保存会话的时间间隔        |
| 最大历史会话数   | 保留的最大历史会话数量        |
| 数据目录         | 数据存储路径                  |

### 稳定性参数

| 参数           | 说明                         |
|----------------|------------------------------|
| 请求超时时间   | API 请求超时时间（秒）       |
| 最大重试次数   | API 请求失败时的最大重试次数 |
| 并发限制       | AI 请求的最大并发数           |
| 缓存大小       | 响应缓存的最大条目数          |

## 主题切换

go-on 内置了多种主题风格，可在设置中切换：

| 主题名称          | 风格描述                                     |
|-------------------|----------------------------------------------|
| 简约（Default）   | 清爽简洁的默认界面风格                        |
| 国风              | 中国传统文化元素，典雅配色                    |
| 武侠              | 江湖侠客风格，豪迈配色                        |
| 山水              | 水墨山水画风格，淡雅配色                      |
| Hello Kitty       | 可爱粉色系风格                                |
| 为人民服务        | 复古红色风格                                  |

切换主题后即时生效，无需重启应用。

## 多语言支持

在 **Settings（设置） → 语言选择** 中，可以切换 GUI 界面语言：

- **English** — 英文界面
- **简体中文** — 简体中文界面
- **繁體中文** — 繁體中文界面

切换语言后整个界面实时生效，包括菜单、Tab 标签、提示信息等所有文本内容。
