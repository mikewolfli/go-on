### F 区（自行扫描，子代理两次被取消）

三端 SDK 契约问题：
- Node `workflowExecute(workflow, params)` 传 `{workflow, params}`，后端 `workflow.execute` 只读 `params.task`（exec_pack/execute.rs `params_task`）→ 传参无效
- Node `traceGet(traceId)` 传 `trace_id`，后端 `trace.get` 只读 `limit`（config_handlers.rs:106）→ 传参无效
- Node `governancePlanGet(planId)` 传 `plan_id`，后端 `governance.plan.get` 不读任何参数（plan.rs:9）→ 传参无效
- Rust SDK 缺 session 系列方法（TS/Node 有 sessionNew/sessionPrompt/sessionClose/sessionList/sessionResume/sessionSetMode/sessionSetConfigOption）
- TS SDK 缺 configReload（Rust/Node/Python 有）
- Python SDK 缺 session 系列方法
- Node SDK `traceGet` 与其余三端 `trace_get(limit)` 签名不一致

已确认正常项：后端路由 /v1/responses、/v1/models、/v1/state/events、/health/ready、/chat/stream 均存在（http.rs）；verify-zed-integration.sh 端口 8090 正确；README 7 sub-bus 描述与 Cargo.toml 一致（local=6+distributed-memory）；CHANGELOG 1.5.0 与 Cargo.toml 匹配。
