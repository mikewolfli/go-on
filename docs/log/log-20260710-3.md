### 修复 H0-1: now_iso8601() 日历算法修正
**文件**: `capability_bus/memory_bus.rs`
**问题**: `day_of_year / 30` 假设每月30天，产生错误月份/日期
**修复**: 实现完整公历算法：
- 逐年计算（含闰年判断：%4=0且%100!=0或%400=0）
- 逐月查询 MONTH_DAYS 表 `[31,28,31,30,31,30,31,31,30,31,30,31]`
- 2月闰年 29 天
```rust
// 示例: day_of_year=60 → 正确: 3月1日 (之前错误: 2月1日)
```

### 修复 H0-2: semantic_matcher 死代码清理
**文件**: `src/intelligence/semantic_matcher.rs`
**问题**: 
- `known_tags` HashSet 构建（3个 static 的并集）但只在 `else if` 中检查，而该 else if 永远不可达（因为已知 tag 已被前面 3 个 specific 检查捕获）
- `if total == 0` 守卫永远不可达（`tags.is_empty()` 已在前面检查）
**修复**: 删除所有死代码：known_tags 构建、else if 分支、total==0 守卫

### 修复 H0-3: EvolutionHistory::Drop block_on 替换
**文件**: `self_evolution/evolution_history.rs`
**问题**: `Drop` 中使用 `Handle::current().block_on()` 做异步写文件，在非 async 上下文（如同步 Drop）中会 panic
**修复**: 
```rust
impl Drop for EvolutionHistory {
    fn drop(&mut self) {
        if let Some(path) = self.path.take() {
            let data = self.history.clone();
            std::thread::spawn(move || {
                if let Ok(json) = serde_json::to_string(&data) {
                    let _ = std::fs::write(&path, &json);
                }
            });
        }
    }
}
```

### 修复 H1-1: 共识存根 → 真实成员立场查询
**文件**: `council/quorum/consensus.rs`
**问题**: 所有成员硬编码为 Support，无真实辩论
**修复**: 添加 `member_position()` 方法，基于 reputation accuracy 查询每个成员的立场：
- accuracy >= 0.6 → Support
- accuracy >= 0.3 → Oppose
- accuracy < 0.3 → Abstain
- 无记录 → Support（新参与者默认）
并映射为 `position_to_vote_option()`：Support→"support", Oppose→"oppose", Abstain→"abstain"
