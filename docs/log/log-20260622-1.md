## 一、扫描发现的重大问题汇总

### 🔴 P0 — 严重性能/安全问题

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | HNSW 索引 `ensure_hnsw_index()` 标记 `#[allow(dead_code)]`，从未被调用 | `memory/vector.rs:956-1030` | O(log N) 搜索路径永远无法启用，始终 O(N) 全表扫描 |
| 2 | `upsert()` 中 HNSW double-lock：先后获取释放两次锁 | `memory/vector.rs:637-658` | 多余锁竞争，降低并发写入性能 |
| 3 | `search()` 中 TOCTOU 竞争：先检查 HNSW 是否存在，释放锁后再使用 | `memory/vector.rs:707-719` | 并发下可能错过 HNSW 索引构建 |
| 4 | PostgreSQL 无连接池 — `Mutex<postgres::Client>` 全局串行化 | `memory/*.rs` 三处 | 多用户场景所有数据库操作顺序执行 |
| 5 | `TenantBudgetEnforcer` 三个独立 `std::sync::Mutex` — lock-ordering 死锁风险 | `governance/hardening.rs` | 多线程并发写入时存在死锁可能 |
| 6 | `SemanticResponseCache::start_background_cleanup()` 在 `tokio::spawn` 中使用 `std::sync::RwLock` | `memory/semantic_cache.rs` | 阻塞 tokio worker 线程，可能造成 runtime 饥饿 |
| 7 | `Vec<String>` 类型的 `filter_map` 在 `upsert` 中存在空收集后由 `serde_json::to_string` 编码，每 upsert 一次完整收集 | `memory/vector.rs:614-622` | 每 upsert 收集所有行仅用于 eviction |

## 二、修改一览

### Change 1: 修复 HNSW 索引 — 接线 + 修复双锁 + TOCTOU

**文件**: `src/memory/vector.rs`

1. **删除 `#[allow(dead_code)]`** 从 `ensure_hnsw_index()` — 改为在 `search()` 中实际调用
2. **合并 upsert 双锁** — 将两个 HNSW 锁操作合并为一次锁获取
3. **修复 TOCTOU** — search() 中一次性获取锁、检查并构建 HNSW 索引

### Change 2: 删除 ClusterIndex 死代码

**文件**: `src/memory/vector_index.rs`

- 删除 `ClusterIndex` 结构体及所有方法 (~200行 k-means 实现)
- 保留 `VectorIndex` 核心功能

### Change 3: 添加 PostgreSQL/SQLite 连接池

**文件**: `Cargo.toml`

- 添加 `deadpool-postgres` crate（用于 PostgreSQL 连接池）
- 添加 `deadpool-sqlite` crate（用于 SQLite 连接池）
- 更新 workspace dependencies

### Change 4: 修复 TenantBudgetEnforcer 锁

**文件**: `src/governance/hardening.rs`

- 将三个独立 `std::sync::Mutex` 合并为单个 `Mutex<BudgetState>` 结构体

### Change 5: 修复 SemanticResponseCache 异步阻塞

**文件**: `src/memory/semantic_cache.rs`

- 将 `std::sync::RwLock` 替换为 `tokio::sync::RwLock` 在 background cleanup 中
- 或将 background cleanup 使用 `spawn_blocking`

### Change 6: 接线 SKILLS 系统

**文件**: `src/core/bootstrap.rs`

- 在 `perform_bootstrap()` 中添加 SKILL 发现和注册
- 调用 `discover_and_register_local_skills()`
- 调用 `set_prompt_skill_agent()`

### Change 7: 修复测试

- 移除 `test_federated_learning_e2e.rs` 中 `#[ignore]`
- 修复 `autonomy_benchmark.rs` 中弱断言
