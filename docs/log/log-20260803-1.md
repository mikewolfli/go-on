## 二、能够统一的链路

1. **统一缓存层** — `TokenMultiLevelCache`(L1/L2/L3) + `SemanticResponseCache` + `MemoryResponseCache` + `FastPathCache` 合并为单一内存缓存实体（阈值可配 exact/semantic），全部实现 `orchestration/cache_layer.rs` 的 CacheLayer trait；三套 SQLite（ResponseCache/VectorStore/MemoryPersistence Warm）合并为一个库 + tier/kind 列；哈希实现统一到 `embedding_provider.rs:52 local_hash_embed`（vector.rs:1257 已标注 canonical），cosine 统一调 `shared/math.rs`。
2. **统一限流原语** — 以 `shared/token_bucket.rs` 为唯一原语，给 BucketMap 增加 consume_n/evict_idle/状态查询，`RateLimitMiddleware` 与 `PhaseRateLimiter` 退化为纯配置薄层；`TenantBudgetEnforcer` 与 `RateLimitMiddleware` 收敛为一个 tenant 准入层；rpm/60 换算收敛到一处。
3. **统一审计模型+单一汇** — 以 `governance/audit.rs::AuditRecord` 为唯一模型、`HarnessBus.audit_log`(ThreadSafeAuditLog) 为唯一汇：security_governor/hardening::AuditLogger/AgentAuditLog 全部 `From` 转换写入全局汇；`audit_health()` 接线真实 `len()/last_write_time()`；`orchestration/audit.rs` 生产零使用→删除；ISO-8601 格式化收进 `shared/timestamps.rs`。
4. **stdio 主循环合并** — 共享 `StdioRpcLoop`（线程+mpsc 读行→分发到 AcpServer/McpServer），顺带修掉 MCP tokio stdin 挂起；两套 raw HTTP 服务器合并（或换 hyper/axum），SSE framing 统一委托 `acp/impl/runtime/sse.rs:34 write_sse_event`。
5. **状态同步协议单一事实源** — 以 `go-on/src/protocol/state_sync.rs` 为唯一定义，发布 JSON Schema（或由 contracts 生成），GUI/vscode 类型生成产出；重连退避统一按 `contracts/cross-client-sync.md`（当前 GUI 固定 5s/10s 与文档不符）。
