## 本轮发现的真实问题及修复

### 🔥 Fix 1: `autonomy_loop.rs` — 未使用变量 `selected_model`
- **位置**: `src/acp/helpers/autonomy/autonomy_loop.rs:154,205`
- **根因**: `selected_model` 变量被赋值但从未被读取
- **违反原则**: 编译产生 `unused_variables` 警告
- **修复**: 移除 `selected_model` 变量，模型检测标记仅做 continue 不存储

### 🔥 Fix 2: `markdown_renderer.rs` — `render_markdown` 使用 `#[allow(dead_code)]` 绕过
- **位置**: `src/cli/markdown_renderer.rs:33`
- **根因**: `render_markdown` 函数仅用于测试但使用 `#[allow(dead_code)]` 标记在生产代码中保留
- **违反原则**: Principle #14 — 禁止添加 `#[allow(dead_code)]` 替代真正的接线或删除
- **修复**: 将整个函数移至 `#[cfg(test)]` 保护下（测试构建仍然可用，生产构建不包含）

### 🔥 Fix 3: `step.rs` — `StepEntity.id` 字段多余
- **位置**: `src/orchestration/tool/extended/step.rs:37-40`
- **根因**: `StepEntity.id` 字段在构造函数中被赋值但从未在生产代码中读取，仅用于测试断言
- **违反原则**: Principle #9 — 无意义的 dead code
- **修复**: 移除 `StepEntity.id` 字段，`parse_entity_line` 中的 ID 解析改为仅验证（使用 `_id`），测试改为验证返回非空

### 🔥 Fix 4: `model_router.rs` — `enable_high_risk_vote` 字段使用 `#[allow(dead_code)]`
- **位置**: `src/acp/helpers/agent/model_router.rs:30-51`
- **根因**: `HighRiskVoteConfig.enable_high_risk_vote` 字段仅在构造函数中用于推导 `enable_high_risk_multi_agent_vote`，存储后从未被读取
- **违反原则**: Principle #14 — 禁止 `#[allow(dead_code)]` 假修复
- **修复**: 从结构体中移除 `enable_high_risk_vote` 字段，`enable_high_risk_multi_agent_vote` 在结构体字面量中直接计算

### 🔥 Fix 5: `policy.rs` — `WorkGradeDecision.requested` 和 `decision_action` 字段未接线
- **位置**: `src/acp/helpers/governance/policy.rs:163-173`
- **根因**: 两个字段被构造后从未在生产代码中被读取（仅测试使用）
- **修复**: 在 `harness_bus/mod.rs:decide_work_grade_for_task()` 中接入这些字段 — 使用 `d.requested` 和 `d.decision_action` 替代重新计算，消除 dead_code 同时减少重复计算

### 🔥 Fix 6: `autonomy_loop.rs` — 冗余闭包调用 clippy 警告
- **位置**: `src/acp/helpers/autonomy/autonomy_loop.rs:246`
- **根因**: `(|| { ... })()` 闭包立即调用模式触发 `clippy::redundant_closure_call`
- **修复**: 替换为直接表达式

### 🔥 Fix 7: `pre_route_policy.rs` — `.filter().last()` clippy 警告
- **位置**: `src/acp/helpers/governance/pre_route_policy.rs:161`
- **根因**: `.filter().last()` 触发 `clippy::double_ended_iterator_last`（后变为 `clippy::filter_next`）
- **修复**: 替换为 `.rfind()`

### 🔧 Fix 8: `audio_processor.rs` — 清理注释中的死代码示例
- **位置**: `src/multimodal/audio_processor.rs:663-670`
- **根因**: 文档注释中包含被注释掉的代码示例 `// ```ignore ... // ````
- **违反原则**: Principle #9 — 不允许占位/未完成代码
- **修复**: 移除被注释掉的代码示例
