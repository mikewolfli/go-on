## 最终未闭合项修复: lib.rs/main.rs 导出统一

### 问题
`src/lib.rs:39-84` 和 `src/main.rs:35-79` 包含 ~46 行相同的 `pub use crate::...` 语句。每次增删改模块需同步两个文件。

### 历史尝试
- **Round 7 方案A**: `pub use go_on::*;` — 失败，因二进制需 re-export `pub(crate)` 函数
- **Round 8 方案B**: `include!("_reexports.rs")` — ✅ **成功**

### 方案
创建 `src/_reexports.rs` 作为**单一事实源**：

```
src/_reexports.rs      ← 46 行公共 re-export
    ↙         ↘
lib.rs          main.rs
(include!)      (include!)
+ plan_output   (无额外项)
```

| 文件 | 改动前 | 改动后 |
|------|--------|--------|
| `src/_reexports.rs` | 不存在 | 46 行公共 re-export |
| `src/lib.rs:38-84` | 46 行 `pub use` | `include!("_reexports.rs")` + `pub use plan_output` |
| `src/main.rs:35-79` | 46 行 `pub use` | `include!("_reexports.rs")` |

### 收益
- **46 行 → 1 行** 在两个文件中
- 新增/重命名模块只需修改 `_reexports.rs`
- lib.rs 独有的 `plan_output` 单独加在 lib.rs 中

### 验证
```
cargo clippy --all-targets -- -D warnings  →  零警告 ✅
cargo test (154 selected tests)            →  154/154 passed ✅
```
