## 1. 连接池 (`pg_pool.rs`)

| 之前 | 之后 |
|------|------|
| `Arc<Mutex<Client>>` — 单连接，操作串行化 | `deadpool::Pool<Client>` — 多连接并发 |
| 无连接生命周期管理 | `recycle()` 自动验证连接健康 (`SELECT 1`) |
| 连接失败必须重启进程 | 池自动创建新连接 |

### 架构

```rust
PgPoolPair {
    write: Pool<Client>,   // 主库连接池
    read: Pool<Client>,    // 只读副本池（无副本时=write）
}

// 读操作 → pool.read.get()
// 写操作 → pool.write.get()  
```

## 2. 版本化迁移 (`pg_migrate.rs`)

| 版本 | SQL | 说明 |
|------|-----|------|
| v1 | CREATE TABLE response_cache | 响应缓存表 + 过期索引 |
| v2 | CREATE TABLE vector_memory + phase_summary | 向量存储 + 阶段摘要 |
| v3 | CREATE TABLE session_store | 会话持久化 |

### 执行逻辑

```
启动时:
  CREATE TABLE IF NOT EXISTS _schema_version
  SELECT MAX(version) FROM _schema_version  → current=2
  
  for v in [3..MIGRATIONS.len()]:
    EXECUTE MIGRATIONS[v-1]
    INSERT INTO _schema_version (version, applied_at)
```

## 3. 读写分离

### 配置

```toml
[cache]
connection_string = "postgres://user:pass@primary/db"
read_replica_connection_string = "postgres://user:pass@replica/db"  # 可选

[vector]  
connection_string = "postgres://user:pass@primary/db"
read_replica_connection_string = "postgres://user:pass@replica/db"  # 可选
```

### 路由规则

| 操作 | 路由 | 方法 |
|------|------|------|
| `get()` | `pool.read` | SELECT |
| `search()` | `pool.read` | SELECT + vector |
| `entry_count()` | `pool.read` | SELECT COUNT |
| `put()` | `pool.write` | INSERT/UPSERT |
| `purge_expired()` | `pool.write` | DELETE |
| `clear_all()` | `pool.write` | TRUNCATE |

## 全项目 PostgreSQL 架构总览

```
AppConfig
├── [cache].connection_string           → PgPoolPair.write (主库)
├── [cache].read_replica_connection     → PgPoolPair.read  (副本)
├── [vector].connection_string          → PgPoolPair.write
├── [vector].read_replica_connection    → PgPoolPair.read
│
├── transport_factory::initialize_postgres_backend()
│   ├── 重试 3 次 (1s/2s/4s)
│   ├── connect_postgres(url, sslmode)
│   │   ├── sslmode=verify-full: rustls + webpki-roots
│   │   ├── sslmode=require: rustls + PermissiveVerifier
│   │   └── 无 sslmode: NoTls
│   ├── run_migrations(&mut client)
│   │   ├── _schema_version 表
│   │   ├── v1: response_cache
│   │   ├── v2: vector_memory + phase_summary
│   │   └── v3: session_store
│   ├── SELECT 1 (健康检查)
│   └── create_pool(connect_fn, max_size)
│
└── 运行时
    ├── 读操作 → pool.read.get() → Client from pool
    └── 写操作 → pool.write.get() → Client from pool
```
