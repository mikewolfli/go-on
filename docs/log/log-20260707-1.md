### 🔵 确认无误的全链路闭合

```
用户输入 → CLI chat → Agent(Streaming) → Tool calls(并行) → Follow-up(Agent) → 响应输出
                 ↓
           System msg + cached principles
                 ↓
           Skill registry lookup (RwLock)
                 ↓
           Session auto-save (debounced)
```
