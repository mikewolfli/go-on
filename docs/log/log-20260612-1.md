## Round 1 — P0 紧急修复 (完成)

### R1-1 ✅ O5: OTLP双初始化竞争条件修复 [CRITICAL]

**问题**: `telemetry.rs` 和 `telemetry_enhanced.rs` 各自定义了独立的 `static TRACER_INITIALIZED: AtomicBool`，导致两个模块的初始化守卫相互不可见，可能存在竞态双重初始化。
**修复**: 将 `telemetry.rs` 的 `TRACER_INITIALIZED` 改为 `pub(crate)`，`telemetry_enhanced.rs` 移除自己的定义并 `use crate::observability::telemetry::TRACER_INITIALIZED`。
**文件**: `src/observability/telemetry.rs`, `src/observability/telemetry_enhanced.rs`

### R1-2 ✅ O2: tools_pack.rs 工具执行指标记录修复 [HIGH]

**问题**: `execute_mcp_tool_call()` 中 `_start` Instant未被用于记录延迟指标。
**修复**: 将 `_start` 改为 `start`，在 async block 执行完后通过 `record_global_operation()` 记录成功/失败和延迟。
**文件**: `src/acp/impl/request/tools_pack.rs`

### R1-3 ✅ M7: TokenCache 后台清理启动 [HIGH]

**问题**: `TokenMultiLevelCache::start_background_cleanup()` 从未在生产代码中调用。
**修复**: 在 `wire_server()` 函数中添加 `tokio::spawn` 启动 token cache 后台清理（60s间隔）。
**文件**: `src/acp/impl/runtime/server_builder.rs`

### R1-4 ✅ M4: Ollama/Qwen3 静默降级嵌入fallback控制 [HIGH]

**问题**: Ollama 和 Qwen3 嵌入提供者在出错时静默回退到 `local_hash_embed`，调用者无法区分。
**修复**: 添加 `fallback_to_hash: bool` 字段（默认 `true` 向后兼容）。当设置为 `false` 时返回零向量。
**文件**: `src/memory/embedding_provider.rs`

### R1-5 ✅ G6: Verdict解析严格化 [MEDIUM]

**问题**: `review_verdict()` 使用 `starts_with("APPROVE ")` 过于宽松。
**修复**: 改为仅允许精确 `"APPROVE"`/`"REJECT"` 或带冒号后跟内容的 `"APPROVE:..."`/`"REJECT:..."`。
**文件**: `src/governance/review_controls.rs`

### R1-6 ✅ G19: 缺失 ManageTenants 权限 [MEDIUM]

**问题**: RBAC无 `ManageTenants` 权限变体。
**修复**: 添加 `Permission::ManageTenants`，在 Admin 默认权限中包含，更新 `as_str()`/`from_str()`。
**文件**: `src/governance/rbac.rs`

### R1-7 ✅ G14: PUA执行计划读取RULES/pua.md [MEDIUM]

**问题**: `build_enforcement_plan()` 从不读取 `RULES/pua.md`。
**修复**: 添加 `enrich_plan_from_rules()` 函数读取并合并规则。
**文件**: `src/governance/pua.rs`

## Round 2 — P1 问题修复 (完成)

### R2-1 ✅ SDK: TypeScript SDK retry策略统一 [MEDIUM]

**问题**: TypeScript SDK 使用 100ms 基础延迟和30%乘性抖动，与其他SDK不一致。
**修复**: 改为 1000ms 基础延迟 + full jitter（AWS策略）。
**文件**: `sdk/typescript/src/client.ts`

### R2-2 ✅ O8: memory_usage_bytes 硬编码0修复 [MEDIUM]

**问题**: `AcpServer::get_status()` 中 `memory_usage_bytes` 硬编码为 `0`。
**修复**: 将 `get_memory_usage()` 改为 `pub(crate)` 并在 `get_status()` 中调用。
**文件**: `src/observability/performance.rs`, `src/acp/server.rs`

### R2-3 ✅ S-NEW1: SecretManager 生命周期修复 [CRITICAL]

**问题**: 背景旋转循环仅做日志不做实际轮换，且 `_manager` 被立即drop导致 SecretManager 立即释放。
**修复**: 将 `_manager` 改为 `manager` 并移入 `tokio::spawn` async block 中保持活跃。
**文件**: `src/security/mod.rs`
