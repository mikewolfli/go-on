## 发现问题与修复清单

### 🛑 P1: vscode-addon SSE 解析器不处理 event 类型 — 流式传输完全断裂

**文件**: `vscode-addon/src/runtime/sseStream.ts`
**严重度**: **Critical**
**类型**: 功能断裂

**问题描述**:
`sseStream.ts` 的 `parseSseChunk()` 函数仅提取 `data:` 行的 JSON 内容，完全不处理 `event:` 行。然而 `runtimeManager.ts` 的 `sendStreamingRequest()` (L925) 根据 `event.type` 字段分发事件（"token"、"done"、"error"）—— 由于解析器不注入事件类型，`event.type` 永远无法匹配，导致:

1. 所有流式 token 都落入 `default` 分支，尝试读取 `event.content`（后端 SSE chunk 事件中不存在此字段）
2. `done` 事件永远不会触发 `onDone` 回调
3. `error` 事件永远不会触发 `onError` 回调
4. 实际效果: vscode-addon 的流式对话功能完全断裂

**与 SSE 协议合约的差异**:
`contracts/sse-protocol.md` 明确要求:
- "Parsers MUST attach the event type to each parsed JSON object (e.g., as an `_event_type` field)"
- 处理 `event:` 行

**修复**:
完全重写 `parseSseChunk()` 以支持完整 SSE 帧解析:
- 按 `\n\n` 分隔帧
- 提取 `event:` 和 `data:` 字段
- 将事件类型作为 `_event_type` 注入 JSON 负载
- 更新测试以覆盖事件类型提取

### 修复 1: vscode-addon SSE 解析器 (P1)

**文件**: `vscode-addon/src/runtime/sseStream.ts`

```typescript
// 重写 parseSseChunk() 为完整 SSE 帧解析器
export interface SseFrame {
  eventType?: string;
  data: Record<string, unknown>;
}

export function parseSseChunk(text: string): SseFrame[] {
  const results: SseFrame[] = [];
  // 按 \n\n 分隔帧
  const frames = text.split("\n\n");
  for (const frame of frames) {
    if (!frame.trim()) continue;
    
    let currentEventType: string | undefined;
    let currentData: string | undefined;
    
    const lines = frame.split("\n");
    for (const line of lines) {
      const trimmed = line.trim();
      if (trimmed.startsWith("event: ")) {
        currentEventType = trimmed.slice(7).trim();
      } else if (trimmed.startsWith("data: ")) {
        currentData = trimmed.slice(6).trim();
      } else if (trimmed.startsWith("data:")) {
        currentData = trimmed.slice(5).trim();
      }
    }
    
    if (currentData === "[DONE]") continue;
    if (!currentData) continue;
    
    try {
      const parsed = JSON.parse(currentData) as Record<string, unknown>;
      if (currentEventType) {
        parsed._event_type = currentEventType;
      }
      results.push({ eventType: currentEventType, data: parsed });
    } catch {
      // Skip malformed JSON
    }
  }
  return results;
}
```

**更新 `runtimeManager.ts`**: 适配新的 `SseFrame` 返回类型，使用 `_event_type` 字段代替 `event.type` 进行路由。
