3. **F33 `run_tests_tool_executes_configured_command`**：同类 cwd 竞争 + spawn 瞬态。加 `#[serial]` + 重试（持续失败仍断言，不跳过）。

5. **F35 `shell_exec_sandbox_confines_writes`**：bwrap 在极端负载下 setup 失败被安全降级为直接执行 → 沙箱约束断言失败。加 `#[serial]` + 约束检查重试（3 次持续未拦截才失败）。
