## 1. LSP TCP 深度集成

### 之前
`go_to_definition`、`find_references`、`apply_code_action` 仅使用正则文件扫描，对复杂符号（同名函数、泛型）精度不够。

### 之后
新增可选的 `lsp_address` 参数（TCP 地址，如 `127.0.0.1:9258`）：

```
lsp_address 提供?      ──是──→ LSP TCP连接 → 精确结果
     │
    否
     │
     ▼
   正则文件扫描（原行为）
```

### 技术实现
- **零新依赖** — 使用已有 `tokio::net::TcpStream`
- **LSP 帧协议** — `Content-Length: N\r\n\r\n` + JSON-RPC 2.0 体
- **完整 LSP 握手** — `initialize` → `initialized` → `textDocument/didOpen` → 查询
- **三个方法**：
  - `textDocument/definition` — 返回 Location[]
  - `textDocument/references` — 返回 Location[]（含上下文）
  - `textDocument/codeAction` → `workspace/applyEdit` — 应用代码动作
- **运行时** — `run()` 内部创建 `tokio::runtime::Runtime` 执行 async LSP 操作（工具执行已运行在 `spawn_blocking` 中）

## 2. 模板引擎升级

### 之前
`template_render` 使用纯字符串替换 `{{var}}`，不支持过滤器、继承等高级功能。

### 之后
新增可选的 `template-engine` feature gate：

```
feature = "template-engine"?     ──是──→ minijinja 渲染（完整 Jinja2 语法）
     │
    否
     │
     ▼
   纯字符串替换（原行为）
```

### 新增依赖
```toml
minijinja = { version = "2", optional = true }
template-engine = ["dep:minijinja"]
```

`minijinja` 特性：零 unsafe、最小依赖、编译快、支持 Jinja2 全语法（if/for/filters/继承）。

## 3. OSV 本地缓存

### 之前
`security_scan` 每次调用都查询 OSV API (api.osv.dev)，重复查询延迟高、浪费带宽。

### 之后
新增 JSON 文件缓存：

```
查询时:   cache key = "{ecosystem}:{package}@{version}"
             │
     cache hit (TTL内)?   ──是──→ 直接返回缓存结果
     │
     否
     │
     ▼
   OSV API 查询 → 存入缓存 → 返回结果
```

### 缓存设计
| 属性 | 值 |
|------|-----|
| 存储位置 | `~/.cache/go-on/osv-cache.json` |
| 格式 | `HashMap<String, {results, cached_at}>` |
| 默认 TTL | 24 小时 |
| 可配置 | `cache_ttl_hours` 参数 |
| 持久化 | 每次 set 后写磁盘 |

## 4. Docker 工具扩展

### 之前
仅有 `docker_ps`、`docker_exec`、`docker_logs`。

### 之后
新增三个工具：

| 工具 | 名称 | 功能 |
|------|------|------|
| `DockerBuildTool` | `docker_build` | 构建镜像，支持path/tag/dockerfile/build_args/no_cache |
| `DockerPushTool` | `docker_push` | 推送镜像到仓库，支持registry参数 |
| `DockerComposeTool` | `docker_compose` | docker compose up/down/build/logs/ps/restart/stop/start |

## 设计决策总结

| 决策 | 选择 | 理由 |
|------|------|------|
| LSP 依赖 | 零新增，裸 TCP | `tokio` 已有，避免 `lsp-server`/`lsp-types` 产生大量依赖 |
| 模板引擎 | 可选 feature | 默认不增加编译时间，需要时启用 |
| OSV 缓存 | JSON 文件 | 轻量、无需 SQLite、适合少量缓存数据 |
| Docker 扩展 | 子进程 CLI | 跟随已有 `docker_*` 模式，零新依赖 |
