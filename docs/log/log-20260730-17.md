## 二、本轮已执行的修改

### 1. 🔴 双重限流门控合并 (H1) — `src/acp/impl/request.rs`
- 删除条件限流块（entry_auth/governance 开启时额外扣令牌）
- 保留唯一无条件下限流门控，`anyhow::bail!` 改为结构化 `send_error(-32029)`（客户端可收到 JSON-RPC 错误）
- **效果**: 每请求只扣 1 令牌；限流阈值不再悄悄减半；错误契约统一

### 2. 🔴 限流速率 60 倍 bug 修复 (H1b) — `src/protocol/rate_limit.rs`
- `try_consume_tenant` 的 `refill_rate = rpm / 60.0`（与 `check()` 语义一致）
- **效果**: 租户限流按配置 RPM 真实生效（此前形同虚设）

### 3. 🔴 第三处重复限流检查移除 (H1c) — `src/acp/helpers/governance/pre_route_policy.rs`
- 删除 multi-users-server 下对同一 token bucket 的 `limiter.check()` 重复扣费

### 4. 🟡 agent 就绪探测并行化 (M3) — `src/acp/impl/chat.rs`
- `filter_runtime_ready_agents` 串行 for 循环 → `futures_util::future::join_all` 并行
- **效果**: observe→think 热路径最坏延迟从 N×250ms 降至单次 250ms

### 5. 🟡 60s 空转维护循环移除 (H2) — `src/acp/background.rs`
- 删除 `run_background_maintenance_loop` 及其 spawn（purge 恒 0 + GC 空 store）
- 保留 `run_maintenance_cycle`（health/lifecycle API 手动触发）
- `BackgroundContext` 移除无用 `shutdown_notify` 字段

### 6. 🟡 MemoryBus 只写路径移除 (H1-memory) — `src/intelligence/capability_bus/feedback.rs`
- 删除 feedback 每请求向 L1 MemoryResponseCache + L2 SQLite 写入唯一 key 的 store 调用
- 保留 DistributedMemoryBus（跨节点持久化是激活通道）
- **效果**: 停止 L1 缓存与 SQLite 的无读取垃圾累积

### 7. 🟢 重复 LocalVoter 移除 (M3-intel) — `src/intelligence/hub.rs`
- 删除完全相同的第二个 `LocalVoter("local")`，保留 `"local-agent"`
- 文档注释 5→4 voter 同步更新

### 8. 🟢 `enable_delphi_debate` 接线 (M1-intel) — `src/acp/impl/runtime/server_builder.rs`
- `init_intelligence_hub(false, ...)` → `init_intelligence_hub(server.runtime_config.enable_delphi_debate, ...)`
- 配置字段从死配置变为真实生效（默认 false 无行为变化）

### 9. 🟢 重复 `with_live_performance` 移除 (M7-intel) — 同上文件
- 删除第二行重复的 builder 调用

### 10. 🟢 orchestrator 死代码移除 (M7-request) — `src/orchestration/orchestrator.rs`
- 移除 `record_model_execution`（自由函数）、`select_mode_runtime_with_registry`、`execute_with_mode`、`execute_tool_pipeline`、`select_skill_semantic`
- 5 个测试迁移到生产函数 `mode::resolve_mode_runtime`（行为等价，`GenericModeRuntime::new(kind, registry, None)` 完全一致）
- 清理 8 个不再使用的导入

### 11. 🟢 skill 语义匹配死路径移除 — `src/intelligence/semantic_matcher.rs`

### 12. 🟢 AlertManager 死代码移除 (H5a) — `src/observability/alert_manager.rs`

### 13. 🟢 `vote_on_decision` + `multi_voter` 字段移除 — `src/intelligence/capability_bus/core.rs`
- 移除 `sub-bus-voter-future` 下无任何调用者的 `vote_on_decision` 方法及仅其使用的 `multi_voter` 字段

### 14. 🟢 孤儿 API 标记 — `src/orchestration/tool/pipeline.rs` + `src/orchestration/mod.rs`
