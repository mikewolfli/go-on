## Round 4 — Feature/Config Cleanup

### Issues Found & Fixed

#### R4-1. Three dead feature flags with orphaned dependencies
**Files**: `Cargo.toml`

**Problem**: `charting`, `data-collection`, and `image-extra` features defined in Cargo.toml but never referenced by `#[cfg(feature = ...)]` anywhere in source code. Each pulled in an optional dependency (`plotters`, `serialport`, `imageproc`) that was compiled but never used — only in the `full` profile but silently bloatful even there.

**Fix**: Removed the feature definitions and their optional dependencies. Left comments documenting they're reserved for future use. The `full` profile no longer includes them.

#### R4-2. Broken path in first-run.sh
**Files**: `scripts/first-run.sh`

**Problem**: `ROOT_DIR` was calculated as the `scripts/` directory (via `dirname "$0"`), causing cascading path bugs:
- `$ROOT_DIR/backend/go-on` resolved to `scripts/backend/go-on` (non-existent)
- `$ROOT_DIR/scripts/skills-setup.sh` resolved to `scripts/scripts/skills-setup.sh` (double nesting)

**Fix**: Added `SCRIPT_DIR` intermediate variable, computed `ROOT_DIR` as the parent of `SCRIPT_DIR`. Updated binary paths from non-existent `backend/go-on` to standard `target/release/go-on` / `target/debug/go-on`. Skills-setup path now correctly resolves.
