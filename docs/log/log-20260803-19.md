## 七、残留项（已识别，需架构决策或行为确认）

1. **HashChainAuditor 每请求同步磁盘写**（`audit_integrity.rs` append 内 OpenOptions+writeln）——与统一审计 sink 合并属架构决策，暂保留（哈希链完整性是安全特性）。
2. **full_auto 子系统生产不可达**（full_auto/* + fast_path_cache.rs 部分，~2000 行）——删除收益大但需独立验证全部引用面（含 tests/contract_tests）。
3. **RecoveryOrchestrator 零生产调用者**（recovery/*，~900 行）——AutonomyLoopConfig.recovery_orchestrator 字段为只写；删除或接线待确认。
4. **harness_bus 死实例字段**：brain_loop（从不 run_async）/omnipotent_mode（record_action 零调用）/artifact_layer/token_chain（零读取）——health payload 报恒默认 profile；删除或接线待确认。
5. **Q 表无界增长**（reinforcement_bus.rs q_table 无 eviction，每次 evolve/decide 全表扫描 O(n)）——需二级索引 + LRU 上限，架构级改动。
6. **autoreflect 30s 后台循环**：报告仅 info 日志（get_report/list_reports 零生产消费者）——有配置门控 + 有界存储，保留为设计特征（BLUE56-B10）。
7. **policy_reloader 未接线**——log-18 已定：自动接线不安全（默认 RedLine deny@0.5 会硬阻断），保留显式运维决策。
