## 修复清单

### 修复 1: 消息内容 ↔ 模式能力交叉验证

**文件**: `src/acp/helpers/governance/pre_route_policy.rs`

新增 `validate_mode_capability()` 函数，在 `evaluate_pre_route_policies()` 最开头调用：

```
evaluate_pre_route_policies()
  ├── validate_mode_capability()    ← 新增：交叉验证
  ├── HarnessBus 策略评估
  ├── RateLimit 检查
  └── TenantBudget 检查
```

**检测逻辑**:
1. 拼接所有 user 消息为任务描述
2. 通过正则模式识别内容特征:
   - `https?://` → URL 检测（需要 HTTP fetch）
   - 代码块（` ``` `）→ 代码编辑
   - 文件引用（`src/main.rs`）→ 代码编辑
   - 执行关键词（`create|build|delete|deploy|connect`）→ 执行操作
   - 安全敏感词（`password|secret|token|credential`）→ 安全操作
   - 规划关键词（`plan|design|architecture`）→ 规划
   - 短问题（<50字符，无代码/URL）→ 简单问答
3. 映射到最低所需模式等级: Ask(0) → Plan(1) → Edit(2) → SafeGuard(3) → FullAuto(4)
4. 当前模式等级 < 所需等级时 → `anyhow::bail!()` 带用户友好提示

**示例行为**:
```
用户输入: "帮我把这个 https://agent-world-test... 接入Agent World"
当前模式: ask
→ 返回: "当前模式 'ask' 不适合此请求。检测到 URL 需要网络请求能力，请切换到 'safeguard' 或 'full_auto' 模式。"
```

### 修复 2: SafeGuard review gate 死代码

**文件**: `src/acp/impl/chat_phases.rs:578-598`

**修改前**:
```rust
ModeKind::SafeGuard => {
    if let Some(span) = None {  // ← 永远 false
        let outcome = run_review_gate(server, messages, options, span, trace).await;
        outcome.passed
    } else {
        true  // ← 永远 true，gate 不生效
    }
}
```

**修改后**:
```rust
ModeKind::SafeGuard => {
    let outcome = run_review_gate(
        server,
        &params.messages,
        resolve_out.phase.options.as_ref(),
        None,  // span: 无 OTel context 时用 None，review 仍会运行
        trace,
    )
    .await;
    if !outcome.passed {
        tracing::info!("safeguard review gate blocked execution");
    }
    outcome.passed
}
```

当 review gate 失败时 `review_passed=false`，autonomy round 跳过，执行 fallback 路径。
