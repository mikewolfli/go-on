## 第2轮修复详细清单

### 修复 G0-1: GUI Chat thinking 重复问题
**文件**: `gui/src/views/chat/chat_impl/runtime.rs`
**问题**: ChatCompleted 处理时，`m.thinking.push_str(&thinking)` 将完整 thinking 追加到已累积的增量 thinking 之上，导致内容重复。
**修复**: 
```rust
// 修改前:
if !thinking.is_empty() {
    if m.thinking.is_empty() {
        m.thinking.clone_from(&thinking);
    } else {
        m.thinking.push_str(&thinking);  // 追加 → 重复!
    }
}

// 修改后:
if !thinking.is_empty() {
    m.thinking = thinking;  // 直接用完整结果替换
}
```

### 修复 G0-2: GUI Chat 流式消息跳过哈希计算
**文件**: `gui/src/views/chat/chat_impl/ui/old_ui_content.rs`
**问题**: 流式消息的哈希在脏检查中被完整计算，但由于 `is_last` 短路，永远不会被用于跳过渲染。
**修复**: 将 `is_last` 检查移到哈希计算之前，流式消息直接跳过哈希计算。

### 修复 G1-1: default_model() 移入 trait 默认实现
**文件**: `src/agents/agent.rs` (trait 定义) + 30 个 agent 文件
**问题**: 30+ 个 agent 文件有完全相同的 `fn default_model()` 实现。
**修复**: 
1. 在 Agent trait 中添加默认实现:
```rust
fn default_model(&self) -> Option<ModelInfo> {
    self.available_models().into_iter().find(|m| m.is_default)
}
```
2. 从 29 个 agent 文件中删除此方法
3. 保留 `copilot.rs`（自定义实现）、`openai_compatible.rs`（使用 `.next()`）的覆写

### 修复 G1-2: 删除 `let chat_messages = messages;` 冗余绑定
**文件**: 35 个 agent 文件
**问题**: 每个 agent 的 `chat()` 方法中都有 `let XXX = messages;` 的无意义重绑定。
**修复**: 删除重绑定行，直接将 `messages` 变量传入闭包。

### 修复 G1-3: 为 test/mock agent 添加 available_models()
**文件**: 
- `acp/helpers/agent/agent_selector.rs`
- `orchestration/multi_agent_pipeline.rs`
- `acp/impl/chat_tests.rs`
- `src/agents/agent.rs` (LocalEchoAgent 等)
**问题**: `available_models` 变为 trait 必需方法后，这些 mock agent 未实现。

### 修复 G2-1: DeepQuest 功能补全
**文件**: `src/agents/deepquest.rs`
**问题**: 未导入 `apply_openai_common_options`，手动仅处理温度/top_p，忽略 max_tokens/stop/penalty 等。
**修复**: 导入并使用 `apply_openai_common_options(&mut payload, options);`。

### 修复 G2-2: session_context key_concepts 存根
**文件**: `src/orchestration/session_context.rs`
**问题**: `key_concepts: Vec::new()` 始终为空。
**修复**: 从最近消息中提取有意义的词作为关键概念（长度>4的字母数字词）。

### 修复 G3-1: fast_path_cache 无意义调用
**文件**: `src/orchestration/fast_path_cache.rs`
**问题**: `read_cache_metrics()` 被调用但返回值丢弃，涉及全局 Mutex 获取。
**修复**: 移除调用行和 `read_cache_metrics()` 函数定义。
