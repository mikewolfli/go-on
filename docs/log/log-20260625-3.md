## Issues Found

### P1: Sandbox whitelist feedback black hole (rule #8)
**Where**: `src/governance/hardening.rs` — `SandboxPolicy::check()` returns bare `bool`
**Problem**: When a tool is denied by sandbox policy, the AI caller gets a boolean `false` with no structured feedback about:
- Which sandbox level is active
- What action category was denied
- What tools ARE available at this level
- How to escalate if appropriate

**Fix**: Wrap return value in a struct that includes level info, action, and available alternatives. Enhance `check_tool_in_pipeline` in `pipeline.rs`.

### P2: Pipeline tool-to-action mapping drifts from registered tools
**Where**: `src/orchestration/tool/pipeline.rs` — `pipeline_tool_to_action()` maps ~80 tool names to actions
**Problem**: The mapping is hardcoded and doesn't include newly registered game tools or extended tools. Missing tools silently default to "read" (least restrictive), creating a security gap.

**Fix**: Add a comment-based audit mechanism and ensure ALL registered tools have sandbox policies defined.

### P3: SkillExecuteTool `run()` creates unnecessary Arc + inner Runtime
**Where**: `src/orchestration/tool/mod.rs` — `SkillExecuteTool::run()`
**Problem**: `Arc::new(SkillExecuteTool)` creates a new allocation every call. The SKILL_RUNTIME is a separate single-threaded runtime bypassing the main tokio runtime.

**Fix**: Reuse static Arc, document the sync-to-async bridge pattern.

### P4: SkillsFolderIndex has misleading test names
**Where**: `src/orchestration/skills_folder.rs`
**Problem**: Tests named `test_search_empty_when_no_skills` and `test_search_empty_query` suggest search functionality that doesn't exist. The struct only scans URL sources.

**Fix**: Rename tests to match actual functionality.

### P5: Skill execution missing suggestion when skill not found
**Where**: `src/orchestration/tool/mod.rs` — `SkillExecuteTool::run_async()`
**Problem**: When skill is not found, error says "'{name}' not found in registry" but doesn't offer to list available skills.

**Fix**: Add hint to use `skill_list` tool first.
