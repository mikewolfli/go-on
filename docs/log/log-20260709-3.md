## Runtime Hub 实现总结

### 架构

同 Zed/VSCode 的后台常驻进程模式：

```
go-on hub start
  │  绑定随机 loopback 端口 (127.0.0.1:0)
  │  写入 discovery.json → $XDG_RUNTIME_DIR/go-on/hub/discovery.json
  │  启动 JSON-RPC 2.0 HTTP 服务器
  ▼
Runtime Hub (后台守护)
  ├── hub.handshake   — 身份验证
  ├── hub.status      — 运行时状态
  ├── hub.store       — 持久化键值
  ├── hub.retrieve    — 读取持久化值
  └── hub.list        — 列出所有键
```

### CLI 用法

```bash
# 启动 Hub（前台模式）
go-on hub start --foreground

# 查看 Hub 状态
go-on hub status

# 停止 Hub
go-on hub stop
```
