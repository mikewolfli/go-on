## 2. 核查中修复的问题

### 2.1 `reputation.rs` — 死代码清理

**问题**: `#[cfg(test)]` 下的 `default_enabled()`、`default_alpha()`、`default_degraded()`、`default_excluded()` 函数和 `ReputationConfig` 结构体/impl 未被任何代码引用。clippy 报 `dead_code`。

**原则违反**: principle.md §14（禁止假修复）、§15（禁止不完整修复）

**修复**: 删除 `default_*()` 四个函数和 `#[cfg(test)] ReputationConfig` 结构体（生产代码已使用 `core::config::types::ReputationConfig`）。

**文件**: `src/intelligence/reputation.rs`

### 2.2 `capability_bus/core.rs` — 文档格式违规

**问题**: 文档注释中编号列表明细行缩进不规范，clippy 报 `doc_overindented_list_items` + `doc_lazy_continuation`。

**修复**: 改为标准逐行编号格式。

**文件**: `src/intelligence/capability_bus/core.rs`

### 2.3 `memory_bridge.rs` — 未使用的赋值

**问题**: 测试代码中 `let mut handle = None` 后在下一段立即覆盖，clippy 报 `unused_assignments`。

**修复**: 直接使用 `let handle = tokio::spawn(...)` + 移除 `expect`（直接使用 JoinHandle）。

**文件**: `src/memory/memory_bridge.rs`
