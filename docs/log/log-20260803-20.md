## 三、planner/DAG 统一 — 核查结论（全部记录不修改）

| log-1 项 | 核查结论 | 判断 |
|---------|---------|------|
| ExecutionGraph vs TaskGraph | TaskGraph 是**持久化检查点 schema**（`TaskGraphStore` SQLite+Postgres 双后端 save/load/restore 深度依赖），ExecutionGraph 是**运行时执行图**（orchestration_bus/planner_bridge） | **非重复**（关注点不同），保留 |
| dag_execution_order vs get_ready_nodes | 操作不同数据结构（PlannerExecutionBridge.plan.steps vs ExecutionGraph.nodes/edges） | 非逐行重复，保留 |
| planner_bridge ×2 | brain_loop版（ExecutionPlan→BrainLoopStep）vs acp版（PlannerExecutionBridge 构建+DAG注入） | 同名不同职责，保留 |
| SchedulerConfig ×2 | scheduler.rs（运行参数）vs config/types.rs（TOML schema）字段完全不同 | 命名冲突，保留 |
| TaskContext ×3 | pua.rs / core_dag.rs / workflow_registry 三种不同语义 | 命名冲突，保留 |

> 结论：planner/DAG 领域**运行时 DAG 已唯一**（ExecutionGraph），其余为持久化层/命名混淆，不构成功能重复——与 log-1 报告（基于旧行号）的部分判断不同，属扫描口径修正。

按用户指令攻克 HTTP 合并 / 配置单一模板 / vscode sdk 复用。

## 一、HTTP 服务器合并（MCP vs ACP raw-TCP）✅（逐字重复收敛）

**核查**：MCP `protocol/mcp_server.rs` 自带 3 个与 ACP 逐字/功能重复的 HTTP 辅助函数：
- `extract_content_length`（MCP 本地版）== ACP `runtime/protocol.rs::extract_content_length`（逐字相同，含 RFC 7230 冲突处理）
- `extract_mcp_entry_token` == ACP `runtime/security.rs::extract_entry_token`（逐字相同：Bearer + x-api-key + x-go-on-key）
- `extract_mcp_header_value` == ACP `runtime/protocol.rs::extract_header_value`（功能相同，返回类型 &str→String）

**实施**：
| # | 改动 | 说明 |
|---|------|------|
| 1 | `security.rs::extract_entry_token` 改 `pub(crate)` | 共享给 MCP |
| 2 | MCP 删除 3 个本地函数 | 调用点直接使用 `crate::acp::r#impl::runtime::{protocol,security}` 共享版 |
| 3 | MCP CORS 调用点适配 `Option<String>` → `.as_deref()` | build_cors_headers/build_preflight 签名兼容 |

**保留**：`write_http_json_response` 两版并存（ACP `Connection: close`+shutdown 单请求关闭 vs MCP `keep-alive`+flush 连接复用——**语义性差异**，非重复）；accept 循环/TLS 构建/SSE 心跳 payload 各不同（MCP 发 JSON-RPC ping，ACP 发 state_sync Heartbeat）。

**验证**：cargo build 0 警告；mcp 20 / protocol 61 / transport_parity 18 全过。

## 三、vscode 复用 sdk/typescript GoOnClient ✅

**架构决策**：vscode 默认 stdio 模式保留（进程生命周期管理/低延迟/无端口优势）；复用落点在 **stdin backpressure 的 HTTP 降级路径**（原手写 fetch + envelope 解析）。

**实施**：
| # | 交付物 | 说明 |
|---|--------|------|
| 1 | sdk `client.ts` 新增公开 `request<T>(method, params)` | 包装私有 jsonRpc（超时/重试/错误归一），供 vscode 任意 method 调用 |
| 2 | vscode `package.json` | dependencies 加 `"go-on-sdk-typescript": "file:../sdk/typescript"`；compile 脚本前置 `build:sdk`（npm run build --prefix ../sdk/typescript） |
| 3 | vscode `runtimeManager.ts` HTTP fallback | 手写 fetch → `new GoOnClient({baseUrl}).request(method, params)`（获得超时/重试/GoOnError 归一）；`import { GoOnClient } from "go-on-sdk-typescript"` |

**验证**：`npm run compile`（build:sdk → tsc → sync-locales）全过；`npx tsc --noEmit` 0 错误。
