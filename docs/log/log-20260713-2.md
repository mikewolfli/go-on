## 1. `respond()` 最优优化

### 问题
`respond()` 先调用 `send_result`/`send_error`，它们再调用 `write_response` → `write_json_line`，多出 2 层函数间接。

### 修改

```rust
// 改造前：respond → send_result/send_error → write_response → write_json_line (4 层)
// 改造后：respond → write_response → write_json_line (2 层)
```

`src/acp/impl/io.rs`：
- `respond()` 直接构造 `JsonRpcResponse` 并调用 `write_response`
- 跳过 `send_result` 和 `send_error` 的中间层
- 保留 `send_result`/`send_error`/`send_empty_ok` 供剩余的 21 个复杂 handler 使用
