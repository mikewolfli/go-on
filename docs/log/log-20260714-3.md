    agent: Arc<dyn Agent>,
    tool_registry: Option<Arc<ToolRegistry>>,
    objective: &str,

    principles: &Option<Vec<String>>,
    options: &Option<HashMap<String, Value>>,
    config: AutonomyLoopConfig,
    timeout_duration: Option<std::time::Duration>,

    params: AutonomyLoopParams,

## 2. CLI Chat 改进

### 2.1 新增 `/models` 命令

| 文件 | 改动 |
|------|------|
| `src/cli/chat.rs` | 添加 `/models` 命令 handler + HELP_TEXT 更新 + banner 更新 |

**实现**: 调用 `current_agent.available_models()` 列出当前 agent 的所有可用模型，包括模型 ID、名称、是否为默认模型。

### 2.2 新增 `/retry` 命令

| 文件 | 改动 |
|------|------|
| `src/cli/chat.rs` | 添加 `/retry` 命令 handler + HELP_TEXT 更新 |

**实现**:
- 查找对话中最后一条 user 消息
- 截断到该消息之后的所有内容
- 重新运行 `run_agent_with_tools()` 生成回复
- 支持 token 追踪和成本累计

### 2.3 Banner 优化

更新 banner 以显示完整的命令列表。
