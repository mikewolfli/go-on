## 详细变更记录

### 1. 🔴 P0: 统一 ErrorCode 体系

**文件**: `src/core/error.rs` + `src/acp/impl/runtime/http.rs`

#### 新增类型

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(rename_all = "SCREAMING_SNAKE_CASE")]
#[non_exhaustive]
pub enum ErrorCode {
    // 4xx Client Errors
    BadRequest, InvalidRequest, ValidationError, MissingField,
    InvalidFormat, AuthenticationRequired, Unauthorized, Forbidden,
    NotFound, MethodNotAllowed, RateLimitExceeded, RequestTimeout, Conflict,
    // 5xx Server Errors
    InternalError, ServiceUnavailable, BadGateway, CircuitBreakerOpen,
    DatabaseError, ExternalServiceError, ResourceExhausted,
}
```

#### 新增方法

| 方法 | 可见性 | 用途 |
|:-----|:-------|:-----|
| `ErrorCode::http_status() -> u16` | `pub` | 每个 ErrorCode 映射到标准 HTTP 状态码 |
| `error_code_from_status(u16) -> Option<ErrorCode>` | `pub(crate)` | HTTP 状态码反向映射到 ErrorCode |
| `AppError::error_code() -> ErrorCode` | `pub` | 每个 AppError 变体映射到标准化 ErrorCode |

#### 接入链路

```
HTTP Request → route_http_post()/route_http_get()
  → write_http_json_response(socket, status, value)
    ├── status >= 400 AND value has "error" AND no "code" key
    │   └── inject "code" field with ErrorCode (SCREAMING_SNAKE_CASE)
    ├── serialize body to JSON
    └── write "HTTP/1.1 {status} {status_text}\r\n...
              X-Content-Type-Options: nosniff\r\n
              X-Frame-Options: DENY\r\n
              X-XSS-Protection: 0\r\n
              {extra_headers}\r\n{body}"
```

> **影响范围**: 所有 HTTP 错误响应（`/health`、`/chat`、`/rpc`、`/metrics` 等）自动获得标准化错误码。

#### 新增测试（8 个）

| 测试函数 | 验证内容 |
|:---------|:---------|
| `test_error_code_http_status_mapping` | 每个 ErrorCode→HTTP 状态码映射正确 |
| `test_error_code_serde_roundtrip` | 序列化/反序列化完整往返 |
| `test_error_code_serde_screaming_snake_case` | `BAD_REQUEST` 等命名格式正确 |
| `test_error_code_from_status` | HTTP 状态码→ErrorCode 反向映射 |
| `test_app_error_error_code_mapping` | AppError 变体→ErrorCode 映射 |

### 2. 🔴 P0: HTTP Security Headers

**文件**: `src/acp/impl/runtime/http.rs`

**变更**: 在 `write_http_json_response` 和 `write_http_text_response` 的所有 HTTP 响应中添加安全头。

| Header | 值 | 用途 |
|:-------|:---|:-----|
| `X-Content-Type-Options` | `nosniff` | 防止 MIME 嗅探攻击 |
| `X-Frame-Options` | `DENY` | 防止点击劫持 (Clickjacking) |
| `X-XSS-Protection` | `0` | 禁用过时的 XSS 过滤器 |

> **影响范围**: 所有 HTTP 错误响应自动获得标准化 `"code"` 字段。

### 3. 🔴 P0: i18n 多语言错误消息整合

**文件**: `src/acp/impl/runtime/security.rs` · `src/acp/impl/runtime/http.rs` · `config/languages/{en-US,zh-CN,zh-TW}.json`

#### 变更列表

| 位置 | 原内容（硬编码英文） | 替换内容（i18n） |
|:-----|:--------------------|:-----------------|
| `security.rs:65` | `"Authentication required"` + `"AUTH_REQUIRED"` | `t("error.auth_required")` + `ErrorCode::Unauthorized` |
| `security.rs:117-118` | `"Forbidden"` + `"ACCESS_DENIED"` | `t("error.auth_forbidden")` + `ErrorCode::Forbidden` |
| `security.rs:131-132` | `"Insufficient privileges"` + `"PRIVILEGE_ESCALATION_REQUIRED"` | `t("error.auth_insufficient_privileges")` + `ErrorCode::Forbidden` |
| `security.rs:230` | `"ENTRY_AUTH_MISCONFIGURED"` (string) | `ErrorCode::ServiceUnavailable` (enum) |
| `security.rs:256-258` | `"ENTRY_AUTH_REQUIRED"` + hardcoded message | `ErrorCode::Unauthorized` + `t("error.entry_auth_required")` |
| `security.rs:287-289` | `"ENTRY_RATE_LIMITED"` + hardcoded message | `ErrorCode::RateLimitExceeded` + `t("error.chat.rate_limited")` |
| `http.rs:571` | `"chat stream timed out after 120s of inactivity"` | `t("error.chat.stream_timeout")` |
| `http.rs:610` | `format!("invalid RPC request: {}", e)` | `format!("{}: {}", t("error.invalid_request"), e)` |
| `http.rs:637` | `format!("RPC dispatch error: {}", err)` | `format!("{}: {}", t("error.internal_server"), err)` |
| `http.rs:747` | `"Method Not Allowed"` | `t("error.method_not_allowed")` |

#### 新增 i18n 翻译键

| 键 | en-US | zh-CN | zh-TW |
|:---|:------|:------|:------|
| `error.chat.stream_timeout` | chat stream timed out after 120s of inactivity | 聊天流在 120 秒无活动后超时 | 聊天流在 120 秒無活動後超時 |
| `error.internal_server` | internal server error | 服务器内部错误 | 伺服器內部錯誤 |

#### 类型变更

`write_entry_rejection` 函数的 `code` 参数类型从 `&str` 改为 `ErrorCode`，所有调用站点同步更新。这意味着所有 entry rejection 响应现在使用标准化的 SCREAMING_SNAKE_CASE 错误码（如 `"UNAUTHORIZED"`、`"SERVICE_UNAVAILABLE"`、`"RATE_LIMIT_EXCEEDED"`）。

#### 接入链路

```
HTTP Request → security.rs / http.rs
  │
  ├─ t("error.auth_required")      → i18n runtime → localized string
  ├─ ErrorCode::Unauthorized        → serde_json::json! → "UNAUTHORIZED"
  └─ write_http_json_response()
       ├─ injects top-level "code" from status (error_code_from_status)
       └─ writes security headers
```

**影响范围**: 所有经过 `check_http_authorization` 和 `apply_entry_guards` 的安全错误响应现在自动使用用户配置的语言返回错误消息。

### 4. 🔴 P0: License Header CI

**文件**: `.github/workflows/build.yml`

**变更**: 新增 `gate-license` job，在所有 Rust 源文件中检查是否包含 `Copyright`、`MIT License` 或 `SPDX` 标识。

```
gate-license:
  name: License Header Check
  steps:
    - find src -name '*.rs' | xargs grep -L "Copyright\|MIT License\|SPDX"
    - 缺失文件输出为 CI Warning（非 blocking，逐步覆盖）
```

**设计理由**: 
- 不设为 blocking（避免阻塞现有 PR），但提供可视化警告
- 扫描结果在 CI 可观测，便于渐进式添加 License Header
- 非 blocking 避免历史文件的一刀切问题
