## Round 1 — Rust Backend: Dead Code & Lock Cleanup

### Issues Found & Fixed

#### 1. `memory_health/mod.rs` — needless `return` statements (3 instances)
- **File**: `src/observability/memory_health/mod.rs:107,111,115`
- **Fix**: Removed `return` keyword from `query_macos_memory()`, `query_linux_memory()`, `query_windows_memory()` — implicit return from cfg-guarded blocks is sufficient.
- **Impact**: Zero clippy warnings ✅

#### 2. `chat_phases.rs` — Two dead fields in `ThinkOutput`
- **File**: `src/acp/impl/chat_phases.rs:95,104`
- **Fields removed**: `preferred_agent_from_request` and `enable_high_risk_vote` from `ThinkOutput` struct. These were populated but never read outside tests.
- **Cascade removal**: Removed same fields from `AgentSelectionOutcome` in `agent_selection.rs` and removed assignment lines in `think_phase`.
- **Impact**: 4 struct fields + 4 assignment lines removed; ~20 lines of dead code eliminated ✅

#### 3. `inflight.rs` — `Default` impl gated with `#[cfg(test)]`
- **File**: `src/acp/prelude/inflight.rs:43-50`
- **Fix**: Added `#[cfg(test)]` to `impl Default for InflightGuard`. The default implementation created an orphaned `Arc<InflightLimiter>` that was never connected to the shared limiter.
- **Impact**: Prevents accidental misuse in production code ✅

#### 4. `watcher.rs` — Unnecessary Arc wrapper
- **File**: `src/i18n/watcher.rs:203`
- **Fix**: Changed `Arc::new((*mgr).clone())` to `Arc::new(mgr.clone())` — removed unnecessary deref before clone.
- **Impact**: Cleaner code, one fewer level of indirection ✅

#### 5. `model_router.rs` — Documented dead field
- **File**: `src/acp/helpers/agent/model_router.rs:32`
- **Fix**: Added `#[allow(dead_code)]` with reason to `HighRiskVoteConfig.enable_high_risk_vote` — the field documents config completeness and the local variable is used to compute derived fields.
- **Impact**: Justified annotation added ✅

#### 6. `agent_preference.rs` — Documented dead field
- **File**: `src/acp/helpers/agent/agent_preference.rs:51`
- **Fix**: Added `#[allow(dead_code)]` with reason to `AgentPreferenceResult.preferred_agent_from_request` — it's a public API field for external SDK consumers.
- **Impact**: Justified annotation added ✅

### Items Intentionally Left (Justified)

- **execution_intelligence.rs** (~280 lines, `#![allow(dead_code)]`): Has working tests (8), integrates with world model / self model / metacognitive, and the config flag exists. Not meaningless — it's a feature awaiting full wiring. Left as-is per principle #12.
- **Bulkhead::set_limit()**: Public API for future runtime config; tested and documented. Left as-is.
- **hyper_resilience.rs lock ordering**: Documented; not causing issues in practice. Left as-is.

## Round 2 — GUI Rust Frontend Fixes

### Issues Found & Fixed

#### 7. `backend/mod.rs` — Dead `get_chat_endpoint()`
- **File**: `gui/src/backend/mod.rs:232-238`
- **Fix**: Removed the `#[allow(dead_code)]` method. It was documented as "Public API for external SDK consumers" but no external consumers exist.
- **Impact**: Removed one `#[allow(dead_code)]` ✅

#### 8. `views/mod.rs` — Misleading `send_with_retry` name
- **Files**: `gui/src/views/mod.rs:8`, `monitor.rs`, `security.rs`
- **Fix**: Renamed to `try_send_msg` to accurately reflect the single `try_send` call with no retry loop. Updated all 13 call sites across 3 files.
- **Impact**: Clearer naming, no functional change ✅

#### 9. `backend/rpc.rs` — Retry attempts reduced from 1000 to 20
- **File**: `gui/src/backend/rpc.rs:10-11`
- **Fix**: Both `QUICK_RPC_ATTEMPTS` and `FULL_RPC_ATTEMPTS` reduced from 1000 to 20. At 30s max cap per attempt, this gives ~5 minutes of retrying before giving up (vs ~8 hours previously).
- **Impact**: Prevents hours-long retry loops when backend is genuinely down ✅

#### 10. `providers/mod.rs` — Write-only COPILOT_AUTH_CACHE removed
- **File**: `gui/src/views/providers/mod.rs:24-26`, `render.rs:244-248,345-349`
- **Fix**: Removed the `COPILOT_AUTH_CACHE` thread-local cache. It was a write-only sink — stored data but reads were discarded (`let _ = ...`).
- **Impact**: Removed ~15 lines of pointless caching ✅

#### 11. `config.rs` — Mutex replaced with lock-free AtomicU64
- **File**: `gui/src/config.rs:421`
- **Fix**: Replaced `CONFIG_SAVE_DEBOUNCE: LazyLock<Mutex<Option<Instant>>>` with `CONFIG_SAVE_DEBOUNCE_NS: AtomicU64`. Uses nanosecond timestamps with `Ordering::Relaxed` for lock-free reads on the UI thread.
- **Impact**: Eliminates Mutex contention on the UI thread during config saves ✅
