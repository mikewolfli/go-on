## 二、🔴 P0 — 严重问题修复

### Fix 1: `#![allow(clippy::await_holding_lock)]` 从 crate 级→ fn 级

**文件**: `tests/transport_parity_integration.rs`

| 指标 | 修改前 | 修改后 |
|------|--------|--------|
| 范围 | **crate 级** (整个文件 ~2000+ 行) | **`lock_suite_guard()` 函数级** |
| 遮盖 | 所有 async 测试中的 MutexGuard 风险 | 仅发生在源头函数 |
| 安全注释 | 无 | 18 个调用点全部添加 `// SAFETY:` |

**修改**:
- 移除第 1 行 `#![allow(clippy::await_holding_lock)]`
- 在 `lock_suite_guard()` 上添加 `#[allow(clippy::await_holding_lock, reason = "suite-level serialization lock; no cross-runtime deadlock risk as all tests share the same tokio runtime")]`
- 18 个调用点添加 `// SAFETY: suite guard held across .await — suite-level serialization lock`

**影响**: 未来任何新的 `.await` + MutexGuard 组合会被编译器标记，不再被 crate 级 `#![allow]` 静默遮盖。

### Fix 2: `string-similarity` 无用依赖移除

**文件**: `Cargo.toml`

| 指标 | 修改前 | 修改后 |
|------|--------|--------|
| 特性 | `string-similarity = ["dep:strsim"]` | **已移除** |
| 依赖 | `strsim = { version = "0.11", optional = true }` | **已移除** |
| full profile | `"string-similarity"` 在列表中 | **已移除** |
| 代码引用 | 0 处 `#[cfg(feature = "string-similarity")]` | **0 处** |

**影响**: 编译 `--features full` 时不再链接从未被调用的 `strsim` crate，减少编译时间和二进制体积。
