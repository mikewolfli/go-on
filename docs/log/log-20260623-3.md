## 二、🔧 SKILLS 环境按需安装改造

### 修改: `scripts/skills-setup.sh`

**之前**: 步骤 6 (Node.js)、7 (Python)、8 (Rust) 无条件执行 SDK 构建/安装。  
**用户反馈**: "用哪个按哪个，不是一次都安装"。

**修改后**: 每个 SDK 步骤增加智能检测：

| 步骤 | 自动触发条件 | 手动强制标志 |
|------|-------------|-------------|
| 6 (Node.js/TS) | `~/.agents/skills/` 中存在 `.js/.ts/.mjs` 文件 | `--with-nodejs` |
| 7 (Python) | `~/.agents/skills/` 中存在 `.py` 文件 | `--with-python` |
| 8 (Rust) | `~/.agents/skills/` 中存在 `.rs/Cargo.toml` 文件 | `--with-rust` |
| 9 (E2E) | `go-on` 在 PATH 中或 workspace target 中存在 | `--with-e2e` |

新增 CLI 标志:
- `--with-nodejs` — 强制安装 Node.js/TypeScript SDK
- `--with-python` — 强制安装 Python SDK
- `--with-rust` — 强制安装 Rust SDK
- `--all-sdks` — 等效于同时设置以上三个标志
- `--with-e2e` — 强制运行端到端测试

新增 `has_skills_files()` 函数: 扫描 `~/.agents/skills/` 目录下的文件 glob 匹配。

步骤被跳过时显示提示信息（例如 "No JS/TS files found in skills — skip Node.js SDK setup. Use --with-nodejs to force."）。

## 四、🔥 热路径性能审查

### Arc::clone() 审计 — 80+ 处分析

| 严重度 | 文件 | 模式 | 判决 |
|--------|------|------|------|
| 🟢 无害 | `background.rs` | `Arc::clone(...)` | 一次性启动, 后台任务生成 |
| 🟢 无害 | `vote_executor.rs` | `Arc::clone(...)` | 高风险投票, 每次请求最多一次 |
| 🟢 无害 | `council_deliberation.rs` | `.clone()` | 每次请求一次 |
| 🟢 无害 | `autonomy_loop.rs` | `Arc::clone(registry), .clone(messages)` | tokio::spawn 移动闭包必要模式 |
| 🟡 注意 | `agent_preference.rs` | 15-20 `.clone()` 每请求 | 可接受 (~1-2μs) |
| 🟡 注意 | `agent_selector.rs` | `name.clone()` 每候选 | 可接受 |
| 🟢 良好 | — | 6+ 处 `Vec::with_capacity()` | 已优化 |

**结论**: 无意外克隆。所有 `Arc::clone` 是 tokio 异步代码的标准所有权转移模式。

### .to_string() 审计 — 60+ 处分析

**结论**: 所有 `to_string()` 调用语义上必需 — 从 `&str` 过渡到 `String` 用于结构体字段或 `tokio::spawn` 移动闭包。

### `#[cfg(any())]` / `#[cfg(FALSE)]` 死代码扫描

**结论**: 全项目无死条件编译块。所有 `#[cfg(any(...))]` 是合法的 feature gate。
