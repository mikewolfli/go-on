### Issues Found

1. **Lock system `acquire()`/`acquire_async()` behind `#[cfg(test)]`**

   - Added `pub fn skill_registry()` getter for the global `SKILL_REGISTRY`  
   - **Impact**: Cleaner path resolution, skills queryable from any module  

3. **Chat system - blocking, no streaming, no session persistence**  
   - **File**: `src/cli/chat.rs`

     - Added Ctrl+C interrupt handling via `tokio::signal::ctrl_c()`

     - Added /tools, /skills, /stats commands  
     - Added ANSI formatting improvements  
     - Improved streaming output with interrupt support  
   - **Impact**: Much more usable chat experience  

4. **Skills folder scanner test-only**  
   - **File**: `src/orchestration/skills_folder.rs`  
   - **Not fixed**: Module contains test-only helper that duplicates `registry.rs` `discover_and_register_local_skills()`. Low priority.
