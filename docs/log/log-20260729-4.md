## 关键发现详情

### 1. config.toml TOML 结构缺陷

**问题**: `config.toml` 和 `zed-config.toml` 中 OTEL 和 governance 配置字段位于 `[startup_context]` 节之后但在下一个节之前。按照 TOML 规范，这些字段属于前一个节，被 serde 静默忽略。

**修复前**:
```toml
[startup_context]
enabled = true
readme_max_chars = 2000

otel_enabled = true         # ← 错误: 属于 [startup_context]
governance_enabled = true   # ← 错误: 属于 [startup_context]

[agents]
```

**修复后**:
```toml
governance_enabled = true    # ← 根级别: FeatureConfig 是 #[serde(flatten)]
governance_policy_mode = "advisory"

[runtime]
otel_enabled = true          # ← 正确: RuntimeConfig 字段
otel_exporter = "otlp"
...

[startup_context]
enabled = true
...
```
