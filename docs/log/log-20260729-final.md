- 通过 `BrainLoopInner.full_auto_plugin` 存储

### 5. `evolution_loop` + `brain_loop` 反射跨桥 (P3)

- `evolution_trigger_to_reflections()`: EvolutionTrigger → BrainLoopReflection observations
- `brain_reflection_to_evolution_triggers()`: BrainLoopReflection → EvolutionTrigger

**消除 evolution_loop 观察阶段与 brain_loop 反射阶段之间的数据孤岛。**

### 6. 零拷贝 JSON 评估 (P3)

**结论**: 跳过执行。

**原因**: 热路径（`execute_single_tool`）中 `serde_json::from_str()` 的输入 `tool_args_str` 是调用者传入的 `&str`，反序列化为 `Value` 需要分配是不可避免的。实际性能瓶颈是工具执行 I/O（文件读写、子进程、网络请求），而非 JSON 解析。优化收益 < 1%，不值得增加代码复杂度。
