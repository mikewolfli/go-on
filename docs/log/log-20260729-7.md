## 详细变更

### 1. TLS 支持

**之前**: `postgres::Client::connect(url, NoTls)` — 所有连接不加密

**之后**: `sslmode` URL 参数驱动 TLS 选择：

| sslmode | 行为 | 用例 |
|---------|------|------|
| 省略 | `NoTls`（不加密） | 开发环境 |
| `disable`/`allow`/`prefer` | `NoTls`（不加密） | 兼容模式 |
| `require` | TLS + `PermissiveVerifier`（接受所有证书） | 自签名证书 |
| `verify-ca` | TLS + `webpki-roots` CA 验证 | 内部 CA |
| `verify-full` | TLS + `webpki-roots` CA 验证 + 域名检查 | 生产环境 |

**新增依赖** (optional, 仅 `multi-users-server` 启用):
```toml
tokio-postgres-rustls = { version = "0.14", features = ["ring", "webpki-roots"] }
webpki-roots = "1"
```

### 2. 连接重试 + 健康检查

**通用重试包装器** `initialize_postgres_backend`:
```
第1次失败 → 等待 1s → 重试
第2次失败 → 等待 2s → 重试  
第3次失败 → 等待 4s → 重试 → 最终报错
```

**健康检查**: 连接后立即执行 `SELECT 1`，失败视为连接不可用。

### 3. 配置更新

`config.multi-users-server.toml` 添加了 `sslmode` 文档和带 TLS 的连接串示例。

### 4. Hub SQLite 已完全清除

`hub/server.rs` 恢复为纯内存 HashMap vault，不做任何持久化。

## 多用户生产部署连接串示例

```toml
# 生产环境（全加密 + CA 验证）
cache.connection_string = "postgres://user:pass@prod-db:5432/goon_cache?sslmode=verify-full"
vector.connection_string = "postgres://user:pass@prod-db:5432/goon_vector?sslmode=verify-full"

# 内部 CA（自签名）
vector.connection_string = "postgres://user:pass@db:5432/goon_vector?sslmode=verify-ca"

# 开发环境（不加密）
vector.connection_string = "postgres://user:pass@localhost:5432/goon_vector"
```
