### 架构

```
CLI: go-on hub [--port 0]
  → HubServer::new()?.start().await
  → 监听 127.0.0.1:{port} (默认随机)
  → 写入发现文件 $XDG_RUNTIME_DIR/go-on/hub/discovery.json
  → 支持 RPC: hub.handshake, hub.status, hub.store, hub.retrieve, hub.list

Client: HubClient::discover_with_retry()
  → 策略链: env → 发现文件 → is_alive → handshake
  → 指数退避: 50ms → 2s, 30s 超时
```
