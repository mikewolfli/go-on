## Pipeline Governance Architecture

ToolPipeline now properly gates each step:

```
execute_step()
  ├── check_tool_in_pipeline(tool_name, sandbox_level)
  │     ├── map tool_name → GovernanceAction (same logic as evaluator)
  │     └── SandboxPolicy::check(level, action) → denied? return error
  ├── [NEW] wall-clock budget check (max 3600s per pipeline)
  ├── [NEW] max-tool-calls budget (256 per pipeline)
  ├── tracing::info!(allowed = true) on pass
  └── run_single_tool() if all checks pass
```
