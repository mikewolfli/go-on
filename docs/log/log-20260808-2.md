### 遗留 4：MemoryPersistence 读侧接线（D-H1）✅

**根因**：持久层三层（hot/warm/cold）持续写入 + auto_migrate，但 `search_by_session` 等读 API 生产零调用者；且写侧从不携带 `session_id`（`From<CanonicalEntry>` 恒 None），会话级检索永远查不到东西。

**修复（写读闭环）**：
1. 规范 `MemoryEntry` 增加 `session_id: Option<String>`（`#[serde(default)]` 兼容），chat 记忆写入携带 `conversation_id`，`From<CanonicalEntry>` 映射到持久层
2. `MemoryPersistence` 新增 `search_by_session` 委托（warm 层按 session_id 按访问时间倒序）
3. **读侧接入**：`session/load` 与 `session/resume` 响应新增 `memory_context`（该会话持久记忆内容）+ `memory_restored_count`——会话恢复真正记忆感知，"持久化"跨重启生效
