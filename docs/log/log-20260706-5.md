## Round 1 改动 (已合并)

### 1. 🚀 `src/cli/chat.rs` — 并行工具执行 (原顺序→并行)

- **问题:** 所有工具调用串行执行, I/O 密集型工具延迟累积相加
- **改动:** 使用 `futures_util::future::join_all` 并行执行
- **效果:** N 个独立工具延迟从 Σ(t_i) → max(t_i)
- **行号:** ~L880-947

### 2. ⚡ `src/cli/chat.rs` — 专用 stdin 读取任务

- **问题:** 每次循环迭代都 `spawn_blocking` 读 stdin
- **改动:** 专用阻塞线程 + `mpsc::unbounded_channel`
- **行号:** ~L209-233

### 3. 🧹 `src/cli/chat.rs` — 移除 ChatSession::version 死字段

- **行号:** L114-119

### 4. 🔤 `src/cli/chat.rs` — agent_names 排序

- **行号:** L183-184

## Round 2 改动

### 10. 🖥️ `src/cli/chat.rs` — Diff 显示重复修复

- **问题:** `/diff` 和 `/review` 有完全相同 ANSI 彩色 diff 循环
- **改动:** 提取 `display_diff(diff, max_lines)` 共享函数
- **行号:** ~L445-490, L597-644

### 11. 🧠 `src/cli/chat.rs` — 技能注入到 LLM 系统指令

- **问题:** CLI 聊天模式中, `principles` 参数始终为 `None`, LLM 不知道自定义技能存在
- **改动:** 新增 `build_cli_principles()` 函数, 从 ToolRegistry 和 SkillRegistry 提取工具/技能列表, 注入到 `agent.chat()` 的 principles 参数
- **效果:** LLM 现在知道全部内置工具(~90+) 和注册的自定义技能, 可通过 `__tool_call__:` 协议调用
