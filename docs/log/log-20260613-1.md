## 详细变更

### Round 1: 核心修复 (3 issues)

#### 1.1 `acp/helpers/metrics.rs` — 移除重复类型定义
**问题**: 文件中定义了 `MetricsSnapshot`、`RuntimeGaugeSnapshot`、`CircuitBreakerSnapshot`、`LifecycleSnapshot`、`MaintenanceSnapshot` 等类型，均为 `acp/prelude/` 中已有类型的重复副本，且标记了 `#[allow(dead_code)]`。违反原则规则14（假修复反模式）和规则21（迁移幻觉反模式）。

**修复**: 移除了所有重复类型定义、死函数（`histogram_prometheus_lines`、`escape_prometheus_label`）、未使用的 `HISTOGRAM_BUCKETS_SECONDS` 常量。保留了被实际使用的 `stream_chunk_notification`、`stream_done_notification` 函数。

**问题**: 大量函数/类型标记 `#[allow(dead_code)] // F-GAP-49 — reserved`，这些代码从未被调用。违反了原则规则14和规则21。

## 剩余 `#[allow(dead_code)]` 说明

代码库中仍保留约20个 `#[allow(dead_code)]` 标注，均为以下合法场景：
1. **Public API 导出** — 被外部 crate（GUI、SDK、test）使用的类型/常量，如 `acp/prelude/constants.rs`、`acp/prelude/circuit_breaker.rs`
2. **`#[cfg(test)]` 测试辅助** — 仅测试环境下使用的函数，如 `classify_agent_failure`、`execute_tool_calls`
3. **结构体字段** — 公共API结构体的必要字段，仅用于构造而不在本crate内读取，如 `HardnessBudgetProfile.timeout_seconds`、`AgentSwitchState.primary_agent_by_phase`
4. **计划中的公共API** — 标记为"activated, formerly F-GAP-51 — public API surface"的项，如 `is_registered_acp_method`、`AcpErrorCode::ParseError`

这些是符合原则规则的合法用法，不应移除。
