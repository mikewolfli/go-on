## 发现并修复的问题

### 🔴 Critical: Governance 门禁覆盖严重不足

**文件**: `src/governance/status.rs`  
**问题**: `tool_category()` 和 `known_tool_names()` 仅覆盖 ~13 个工具名，而实际注册的工具达 ~78 个。覆盖率仅 **~19%**。导致：
- CLI chat 中的 `execute_simple_tool()` 调用 `quick_check_tool()` 时，大多数工具会被拒（返回 `"Unknown tool — not registered in governance gate"`）
- 例如 `shell_exec` 被拒（虽然其别名 `bash` 可通过）、`apply_patch`、`git`、`http_request`、`cargo_check` 等全部被拒

**修复**: 
- `tool_category()` 从 5 行匹配 → 完整覆盖 **~78 个工具**，按 ReadOnly / Write / Shell 分类
- `known_tool_names()` 从 13 行 → **完整列出的全部工具名**
