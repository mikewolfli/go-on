## 四、残留项（已识别，需行为确认或架构决策）

1. **H4/MED-2**: response_finalizer 每请求 `Planner::plan` + 响应注入 7 个零消费字段（execution_plan/orchestration_alignment 等）——移除会改变响应契约，唯一消费方是 2 个聚合计数器。**建议**: 下轮将 metadata 段改为 debug 开关惰性化。
2. **ConsensusEngine 只写不读**: evolve_consensus 每 50 请求写注册/投票数据，profile()/current_round() 无生产读取方。**建议**: 将 round 数/通过率并入 capability_bus_profile 作为读取方，或移除写路径。
3. **MultiModelVoter 结果丢弃**: multi-users/full 下 Edit 多 agent 路径全并行 LLM 投票（30s/模型超时），结果仅打日志。**建议**: 移出热路径（spawn）或删除。
4. **双 ThreadSafeAuditLog 实例**: hub.rs GLOBAL_AUDIT（/tmp）与 harness_bus.audit_log 并存；热路径同步磁盘写 + 每记录目录扫描。**建议**: 合并单实例 + mpsc 异步落盘。
5. **死配置字段**: `enable_capability_bus`（capability_bus/core.rs）、AutonomyLoopConfig 17 个只写不读字段——零运行时成本，pub API 无警告，按需清理。
6. **scheduler fault_tolerance_timer**: 默认关闭；若开启在全新空引擎上 30s 空转——连真实故障源或删除。
7. **RBAC HTTP 双次评估**: 仅 user_auth_enabled 时传输层+方法层各查一次——分层防御，非扣费，保留。
8. **status 端点硬编码修正**: security_governor/review_controls 已改为 true（反映真实接线）。
