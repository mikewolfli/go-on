## 发现的问题及修复

### P0 - 阻塞性问题（影响核心功能）

#### 1. ✅ StreamingSender 使用 try_send 导致 token 丢失
- **文件**: `src/agents/agent.rs` L464
- **问题**: `StreamingSender::send()` 使用 `try_send()`，channel 满时静默丢弃 token
- **修复**: 改为 try_send + spawn_blocking 阻塞回退，保证 token 不丢失
- **验证**: 代码审查确认 fallback 路径存在

#### 2. ✅ 退出时 SAVE_IN_FLIGHT 自旋等待浪费 CPU
- **文件**: `src/cli/chat.rs` L807-812
- **问题**: 50×10ms 忙等待（最坏 500ms）
- **修复**: 使用 `tokio::sync::Notify` 替代自旋，实现真正的等待-通知模式
- **验证**: Notify 在 Linux 上使用 futex，零 CPU 消耗等待

#### 3. ✅ 移除空函数 `register_specialized_tools()` 和 `register_archive_and_compression_tools()`
- **文件**: `src/orchestration/tool/mod.rs`
- **问题**: 两个空函数只有注释，无实际代码，但被 `new()` 调用
- **修复**: 删除函数定义和调用点
- **验证**: grep 确认无残留引用
