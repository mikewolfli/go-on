## 3. 本轮发现的违规项

### 🔴 Critical 3.1 — `execution_intelligence.rs`: 11× `#[allow(dead_code)]` 替代接线

**原则违反**: #14（禁止 `#[allow(dead_code)]` 替代真正的接线或删除）

**问题描述**:
- 文件 `src/acp/helpers/autonomy/execution_intelligence.rs` 中有 **11 处** `#[allow(dead_code)]`
- 每个都有相同注释 "F-GAP-25: wired by enable_execution_intelligence flag"
- 但没有任何 `enable_execution_intelligence` feature flag 存在
- 整个模块（除测试外）全部是死代码 — `pub(crate)` 函数没有被任何其他代码调用

**修复方案**:
- 新增 feature: `execution-intelligence = []` 到 `Cargo.toml`
- 将 `pub mod execution_intelligence` 包装为 `#[cfg(any(feature = "execution-intelligence", test))]`
- 删除所有 11 个 `#[allow(dead_code)]` 注释

**修复后的状态**: 模块只在 feature active 或 test 环境下编译。不再需要 `#[allow(dead_code)]` ✅

### 🟡 3.2 — `config.toml` 缩进不一致

**描述**: `config/config.toml` 第52行 `production_strict = false` 有 4 个前导空格，相邻行无空格。

**修复**: 移除额外的 4 个空格。✅

### 🟡 3.3 — `vscode-addon/package.json` JSON 语法错误

**描述**: 第5行 `"version": "1.4.3"` 缺少尾部逗号，导致下一行的 `"engines"` 键无法被正确解析。

**修复**: 添加逗号。✅
