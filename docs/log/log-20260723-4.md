### 2.2 关键设计决策

1. **扁平 HashMap + 父指针** — 替代递归 `HashMap<String, AgentNode>`，避免递归 clone
2. **BFS 迭代遍历** — `descendants()` 和 `remove_subtree()` 使用 BFS，避免栈溢出
3. **两级投递** — 仅 `AtMostOnce` + `AtLeastOnce`，去掉 `ExactlyOnce`
4. **简化通配** — 仅 `*` 单层通配，不支持 `**` 和复杂 pattern
5. **直接 acquire** — 去掉 SpawnReservation 预留模式

### 2.3 与原始 BLUE70 的差异

| 项目 | 原始方案 | 实际实现 | 理由 |
|------|---------|---------|------|
| 子节点存储 | 递归 HashMap | 扁平 `Vec<AgentPath>` 索引 | 避免递归 clone |
| 通配符 | 完整 `root/*/coder` | 仅 `*` 单层 | 够用原则 |
| 投递级别 | 3 级 | 2 级 | ExactlyOnce 收益 < 成本 |
| SpawnReservation | 完整模式 | 直接 acquire | 竞态窗口期可忽略 |
| KV 缓存 | 仅 DeepSeek | 通用 `KvCacheProvider` trait | 多模型受益 |
