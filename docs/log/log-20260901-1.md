## 4. 误报修正（子代理结论与实证不符）

1. **chaos.rs drill 子系统被报为"9 处死代码"**：扫描基于 `cargo check`（非 `--all-targets`）——实际 `tests/chaos_drill.rs`（`#[cfg(feature="chaos-testing")]`）真实使用 `run_drills`/`clear`/三个场景函数，`cargo test --features chaos-testing --test chaos_drill` 6 项全过。**未删**；正确激活路径是将其纳入 CI 构建（已通过 full profile 的 release gate 复核，chaos-testing 保持 opt-in 以保住非测试构建零警告）。
2. **`tools_pack.rs` 硬编码 `false,false` 绕过 RBAC**：位于 `harness_bus.is_none()` 的 else 分支，`harness_bus_present=false` 是该分支真实状态，非绕过。
