## 四、🧹 Dead Code 精准化

### Fix: `#![allow(dead_code)]` 从 crate 级变为项级

**文件**: `tests/acp_runtime_rpc_integration.rs`

**修改前**: 第 23 行 `#![allow(dead_code)]` — 覆盖整个 2843 行文件，所有死代码被静默遮盖

**修改后**: 移除 crate 级标注，在 11 个实际死项上加 `#[expect(dead_code, reason = "...")]`:

| 死项 | 类型 | 原因 |
|------|------|------|
| `assert_blue22_runtime_execute_cycle_shape` | fn | extended shape validator |
| `TestScenario` | struct | scenario test framework scaffolding |
| `load_scenarios_from_dir` | fn | scenario file loader, never called |
| `register_mock` | fn | mock-aware harness method |
| `send_request` | fn | mock-aware dispatch |
| `run_scenario_file` | fn | scenario runner |
| `write_managed_service_config` | fn | config variant |
| `write_unknown_deployment_target_config` | fn | config variant |
| `write_warning_config` | fn | config variant |
| `write_shutdown_drain_validation_config` | fn | config variant |
| `write_autotune_enabled_config` | fn | config variant |

**影响**: 任何未来的死代码会立即被编译器标记，不再被 `#![allow]` 遮盖。
