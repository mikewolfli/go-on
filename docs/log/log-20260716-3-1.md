## 三、本轮实施的改进

### 3.1 session/new work_dirs 支持（Zed适配）

**文件:** `src/acp/impl/request/protocol_pack.rs`
**问题:** Zed ACP 客户端发送 `work_dirs: ["/path/to/project"]` 数组，但 go-on 只接受 `cwd: "/path/to/project"` 单字符串。
**修复:** 新增 `work_dirs` 数组解析逻辑：
- 从 params 提取 `work_dirs` 数组
- 如果无显式 `cwd`，使用第一个 `work_dirs` 元素作为 `cwd`
- 将剩余 `work_dirs` 条目合并到 `additional_directories`
- 原 `cwd` 参数行为完全保留

### 3.2 死代码清理（go-on-latex renderer）

**文件:** `crates/go-on-latex/src/renderer.rs`
**移除:** 
- `SvgElement::Rect` 变体（含所有字段）
- `FontStyle::Bold` 变体

### 3.3 MCP Stdio 信号处理

**文件:** `src/protocol/mcp_server.rs`
**问题:** MCP stdio 事件循环缺少优雅关闭支持
**修复:** 添加 `SIGTERM`/`SIGINT` 信号处理和 `tokio::select!` 事件循环
