### R52-2 ✅ 环境相关测试修复：`wrap_command_appends_program_before_args`

- **根因**：该回归测试断言 `SandboxMode::WorkspaceWrite` 下 `wrapped.applied == true`，但 `wrap_command` 在 `bwrap_probe_works()` 失败（macOS 无 bwrap）时如实降级为 `applied: false`（这正是生产行为）。
- **修复**：测试改为环境感知——`applied == false` 时断言 `!bwrap_probe_works()`（降级路径正确）并返回；bwrap 可用时才断言 argv 顺序（program 在 args 前）。argv 顺序回归保护在 Linux 上完整保留，非 bwrap 宿主机不再误报。
- **验证**：`cargo test --lib security::sandbox` 11/11 通过。
