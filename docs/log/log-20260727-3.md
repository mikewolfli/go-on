## 新发现的问题

### 🔴 Issue 1: `vulnerability_scan.rs` 文档代码不匹配 + 静默失败

**文件**: `go-on/src/security/vulnerability_scan.rs:295-327`

`scan()` 方法的文档声称 "In production, this shells out to cargo audit. The stub reports that the real implementation would be invoked" — 但实际代码**确实**运行了 `cargo audit --json`。文档声称是 stub，实际是真实实现。

此外，当 `cargo-audit` 未安装或失败时，返回 `success: false` + **空漏洞列表**。调用者若只检查 `result.vulnerabilities.is_empty()` 会误以为扫描结果安全。

**状态**: ✅ 已修复（更新文档描述真实行为，保留 silent-failure 结构的 error 字段供调用者检查）

---

### 🔴 Issue 3: 两个 Agent World 测试缺少CI跳过机制

**文件**:

- `go-on/tests/agent_world_invitation_test.rs`

两个 `#[tokio::test]` 函数直接调用硬编码的外部端点 (`agent-world-test.chuanshuo.com.cn`)，带有硬编码的邀请URL和token。当端点不可达或token过期时会在CI中失败。

**状态**: ✅ 已修复（添加 `check_server_available()` 函数，在服务器不可达时优雅跳过）
