## Round 2b: Remove Unused Variables + Dead Static Mutex

### Discovery
1. `src/acp/helpers/autonomy/autonomy_loop.rs` — `LATEST_DAG_METRICS` static `LazyLock<Mutex<Option<DagMetrics>>>` was **write-only**: data stored but never read by any consumer. The `store_latest_dag_metrics()` function was called on every autonomy loop iteration, acquiring a mutex for a write with zero readers. This was both dead code and unnecessary lock contention.
   - Also: `let start = Instant::now()` was marked `#[allow(unused_variables)]` (but actually IS used at line 1248 — the annotation was incorrect)
   - `let preferred_tools` was computed but never read (only side effects used)

2. `src/intelligence/reinforcement/federated.rs` — `inner_lock()` method duplicated the poison-recovery pattern already consolidated in Round 1. 10 call sites used this dead method.

### Fix
- Removed `LATEST_DAG_METRICS` static + `store_latest_dag_metrics()` function + `DagMetrics` import
- Removed `#[allow(unused_variables)]` from `start` (it IS used), kept `Instant::now()` call
- Changed `preferred_tools` to `_preferred_tools` to silence warning without annotation
- Removed `inner_lock()` method from federated.rs; replaced all 10 call sites with direct `self.inner.lock().unwrap_or_else(…)`

### Verification
- `cargo build` passes
- `cargo clippy --all-targets -- -D warnings` passes
- All tests pass (27/28 passing; 1 pre-existing flaky integration test)
