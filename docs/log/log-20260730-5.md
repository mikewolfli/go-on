## 1. `MemoryResponseCache` → `SemanticResponseCache` 合并

### 问题
`MemoryResponseCache` 和 `SemanticResponseCache` 都是内存缓存，但：
- 前者存 `String`（response_text），后者存 `Value`（JSON）
- 前者用 `Mutex<IndexMap<...>>` + O(1) LRU，后者用 `RwLock<HashMap<...>>` + O(n) LRU
- 两个缓存在 chat 热路径上独立运作，双重锁开销

### 方案
保留 `MemoryResponseCache` 的 `pub` API 不变，内部委托给 `SemanticResponseCache`（配置为 exact-match 模式）：

```
MemoryResponseCache (pub API)
    └── SemanticResponseCache (inner, similarity_threshold=1.0)
```

### 修改文件
| 文件 | 改动 |
|------|------|
| `src/memory/semantic_cache.rs` | 新增 `put_string()` / `get_string()` 便捷方法 |
| `src/memory/memory_response_cache.rs` | 完全重写为委托模式，删除原版全部实现(~90 行) |
| `src/intelligence/capability_bus/memory_bus.rs` | 适配新返回类型 `Option<String>` |

### 验证
```
cargo test -- semantic_cache → 6/6 passed
cargo test -- memory_bus    → 9/9 passed
```

## 2. 全局 Mutex → RwLock (`ACP_SESSION_STATE`)

### 问题
3 个全局状态使用 `tokio::sync::Mutex`，跨 `.await` 点持有锁。多数操作是只读的（`get`/`contains_key`/`keys`），不应相互阻塞。

### 修改
| 静态变量 | 类型变化 |
|----------|---------|
| `ACP_SESSION_STATE` | `Mutex<HashMap<...>>` → `RwLock<HashMap<...>>` |
| `ACP_PERMISSION_STATE` | `Mutex<HashMap<...>>` → `RwLock<HashMap<...>>` |
| `ACP_PENDING_PERMISSION_REQUESTS` | `Mutex<HashMap<...>>` → `RwLock<HashMap<...>>` |

### 调用点分类更新
| 文件 | 读(.read) | 写(.write) |
|------|-----------|------------|
| `session.rs` | 7 处 | 19 处 |
| `mod.rs` | 1 处 (session_state_for_prompt) | 0 处 |

### 验证
```
cargo test -- session_  → 65/65 passed
cargo clippy --all-targets -- -D warnings → 零警告
```

## 3. `vote_executor` N+1 消息克隆优化

### 问题
`execute_high_risk_vote()` 为 N 个投票 Agent 各调用一次 `run_high_risk_vote_attempt()`，每次克隆 `agent_messages`：
```
vote_executor:   N × .to_vec()  (N=agent 数)
chat.rs:          1 × Vec::clone()   (run_agent_collecting 内部)
→ 总计 N+1 次克隆
```

### 方案
修改 `run_high_risk_vote_attempt` 和 `run_agent_collecting` 的函数签名，从 `Vec<Message>` 改为 `&[Message]`：

| 文件 | 改动 |
|------|------|
| `src/acp/impl/chat/agent_runtime.rs` | `run_agent_collecting` `messages: &[Message]` |
| `src/acp/impl/chat.rs` | `run_high_risk_vote_attempt` `agent_messages: &[Message]` |
| `src/acp/helpers/governance/vote_executor.rs` | 移除 2 处 `.to_vec()` |
| `src/acp/impl/chat/fallback.rs` | 适配 `&msg_clone` |
| `src/acp/impl/chat/vector_context.rs` | 适配 `&summary_prompt` |

### 净收益
```
Before: N+1 次消息克隆 (N=vote agent 数)
After:  2 次常量克隆 (函数内部, 与 Agent 数无关)
```
