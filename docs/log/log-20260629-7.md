## GUI 增强详解

### 1. 新增数据结构 (`types.rs`)

```rust
pub struct SubAgentRecord {
    pub agent_name: String,
    pub action: String,
    pub status: String,         // "running", "completed", "failed"
    pub input: String,
    pub output: String,
    pub tool_calls: Vec<SubAgentToolCall>,
    pub started_at: u64,
    pub duration_ms: u64,
}

pub struct SubAgentToolCall {
    pub tool_name: String,
    pub arguments: String,
    pub result: String,
    pub duration_ms: u64,
}

pub struct CommandRecord {
    pub command: String,
    pub working_dir: String,
    pub exit_code: i32,
    pub stdout: String,
    pub stderr: String,
    pub duration_ms: u64,
}
```

### 2. SSE 事件管道

```
Backend SSE event          → PendingResponse variant     → process_pending()    → Message field
────────────────────────────────────────────────────────────────────────────────────────
_event_type: "sub_agent"   → SubAgentEvent { ... }       → push SubAgentRecord   → message.sub_agent_records[]
_event_type: "command"     → CommandOutput { ... }        → push CommandRecord    → message.command_records[]
```

### 3. 子代理记录面板渲染

每个 AI 消息气泡内的子代理面板：
- **可折叠头部**: `▶/▼ 🤖 Sub-agents (N)` — 点击切换展开/收起
- **状态徽章**: 🟢 completed / 🔴 failed / 🟡 running
- **工具调用**: 工具名、参数、结果、耗时
- **输入/输出**: agent 的输入参数和执行输出
- **全局 toggle**: 消息区域顶部的"Show/Hide all sub-agents" 切换显示全部

### 4. 命令记录面板渲染

每个 AI 消息气泡内的命令面板：
- **可折叠头部**: `▶/▼ ⌨️ Commands (N)` — 点击切换展开/收起
- **退出状态**: ✅ exit=0 / ❌ exit≠N, 颜色编码
- **工作目录**: `dir: /path/to/project`
- **stdout**: 等宽字体，限 500 字符
- **stderr**: 等宽字体+红色，限 500 字符
- **主题感知**: 暗色/亮色模式下使用不同配色
