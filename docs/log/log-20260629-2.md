## 修复记录

### 修复 R1: SkillExecuteTool::run() 移除 block_in_place

**原代码**:
```rust
match Handle::try_current() {
    Ok(handle) => tokio::task::block_in_place(|| {
        handle.block_on(skill_execute_arc().run_async(input))
    }),
    Err(_) => {
        let rt = skill_runtime();
        rt.block_on(skill_execute_arc().run_async(input))
    }
}
```

**新代码**:
```rust
let rt = skill_runtime();
rt.block_on(skill_execute_arc().run_async(input))
```

**理由**: 专用 runtime 在 `OnceLock` 中已提前创建，使用时直接 `block_on` 不会 panic（嵌套 runtime 需要从另一个线程调用，而 OnceLock 保证不在当前线程创建），也彻底避免阻塞 tokio worker 线程。
