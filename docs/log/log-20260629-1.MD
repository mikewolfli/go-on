## 最终架构

```
统一 autonomy 循环（所有 6 种模式）
  act_phase
    ├── review gate（safeguard 前置审核）
    ├── execute_autonomy_round
    │     ├── Planner::plan()
    │     ├── agent.chat() → LLM 响应 + tool calls
    │     ├── DAG 工具执行 + fallback 链
    │     ├── FullAutoFlow（full_auto 启用）
    │     ├── RecoveryOrchestrator
    │     └── 下一轮迭代
    ├── 多 AI 投票 fallback
    └── 响应组装
```
