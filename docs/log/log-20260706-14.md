## Round 3 修复 — 深层 Bug 修复 & 架构优化

### 10. 🔴 修复后台维护循环使用断开缓存的 Bug（内存泄漏）
- **文件**: `src/acp/background.rs:150-165`
- **问题**: `start_background_tasks()` 创建独立 `MemoryResponseCache::default()` 而非复用服务器缓存，导致后台 GC 每 60 秒清理断开实例，**生产缓存从未被清理 → 内存泄漏**
- **根因**: `BackgroundContext.memory_cache` 使用 `Arc<tokio::sync::Mutex>` 不匹配服务器 `Arc<std::sync::Mutex>`，导致用默认值绕过
- **修复**: 
  - `BackgroundContext.memory_cache` 改为 `Arc<StdMutex<MemoryResponseCache>>`
  - `perform_maintenance_cycle()` 参数同改 + 使用 std 锁
  - `start_background_tasks()` 直接克隆服务器 `cache_deps.cache.memory_response_cache`
  - 回退路径同步更新
- **验证**: 后台 GC 循环现在清理**真实**生产缓存

### 11. 🔵 新建共享 `retry_chat_once()` 函数消除 30+ Agent 重复重试逻辑
- **文件**: `src/agents/agent.rs:83-114`
- **问题**: 30+ Agent 提供者（anthropic, openai, gemini 等）复制相同 3 次尝试指数退避重试循环
- **修复**: 新增 `retry_chat_once<F, Fut>()` 泛型辅助函数，封装重试、非重试 4xx 检查、指数退避
- **验证**: 编译通过，现有 Agent 可逐步迁移至此共享函数
