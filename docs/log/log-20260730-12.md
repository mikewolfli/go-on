### 跳过原因（诚实透明）

1. **参数验证路径合并** (§9.3 #2): `validate_required_arguments` 和 `lookup_tool_schema` 在同一个 if 分支中 — 前者决定是否进入错误路径，后者仅在错误路径中提供 schema 细节。两者职责不同，合并会降低代码可读性且无性能收益（错误路径极少执行）。

2. **启动并行化** (§9.1): `check_startup_memory()` 读取 `/proc/meminfo` (同步, <1ms)。`perform_bootstrap()` 执行磁盘扫描和 i18n 加载 (异步, 10-100ms)。并行化不节省 wall-clock 时间，因为 memory check 几乎立即完成。
